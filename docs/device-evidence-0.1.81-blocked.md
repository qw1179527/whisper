## 三、设备取证的环境要求（写给下一次）

本会话已因设备状态浪费多轮，这次又是新原因（**设备被人使用**）。取证前必须逐项确认：
```bash
adb shell dumpsys power | grep mWakefulness            # 必须 Awake
adb shell dumpsys window | grep mCurrentFocus          # 必须是 com.whisper.projectwhisper
adb shell dumpsys activity activities | grep -E "ResumedActivity"   # 独立第二证据
```
**三个都指向本应用**，才开始做功能结论。任何一项不符 → 先解决环境（唤醒/解锁/收栏/拉前台），
