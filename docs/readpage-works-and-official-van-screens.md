## 二、官方资料（首次取得实质正文）

### ① 地点地图（Site Map）—— `phasmophobia.su/knowledge-base/van/site-map`
位置：**货车内左上角**。显示内容（逐条来自正文）：
- 地图名称与**房间平面图**；
- **玩家位置**（颜色与"理智监控器"上的颜色对应），并用发光指示器显示**朝向**；
- **出口**（绿色线标示）；
- **楼层之间的楼梯**（带箭头的简单图标，箭头指示行进方向）；
- **监控摄像头**：正在投放到监视器的那台标**绿色**，其余标**黄色**；
- **配电箱（电闸）位置**（可能随难度变化）；
- 老地图还会用红线标**窗户**；
- **玩家放置的设备**：**运动传感器** = 红线，触发时变绿并伴随声音；**声音传感器** = 半透明橙色区域（老版本黄色）表示作用半径。
- 显示样式随地图版本：**0.4.0 之后重做的地图用俯视图**（含外部区域、物体、光照、贴图）；老地图用简化灰线轮廓。
- **楼层切换**：地图**左侧有上下箭头**，按左键切换；**箭头不循环**（到顶层/底层要点反向箭头才能回来）。

### ② 货车设备总览 —— `phasmophobia.su/knowledge-base/van`
正文列出的**车内设备清单**（这是官方对货车的功能区划分）：
```
Оборудование в фургоне（货车内的设备）
  · Монитор рассудка       理智监控器
  · Карта локации          地点地图
  · Монитор активности     活动监控器
  · Список задач           任务列表
  · Компьютер              电脑
  · Монитор звуковых датчиков  声音传感器监控器
  · Таймер подготовки      准备计时器
```

**与我们现有实现的对照**（《补充说明》§8 + 代码现状）：
| 官方设备 | 我们的实现 | 差距 |
|---|---|---|
| 理智监控器 | 有 `SanitySystem`/`HudModel`，**但货车内没有实体屏** | 需在车厢内建一块屏 |
| 地点地图 | **无** | §8 提到"地点地图可切楼层" —— 需实现（含上述朝向/楼梯/摄像头/传感器标记） |
| 活动监控器 | **无** | 官方"活动监控器"是独立一块屏，§8 未提，但官方清单有 |
| 任务列表 / 剪贴板 | 有 `TaskSystem`；§8 说"货车里有剪贴板可查" | 需在车内建剪贴板实体 |
| 电脑（监控电脑） | 建了几何（`Truck_MonitorScreen`），**无内容** | 需接多画面/夜视 |
| 声音传感器监控器 | **无**（运动传感器/声音传感器道具也还没有） | 随道具四大类一起做 |
| 准备计时器 | **无**（§8：大厅里"除 00:00 计时器外所有屏幕关闭"） | 需实现"00:00"计时器 |

## 三、这对下一步的直接价值
1. **货车内饰要按"多块屏"建**，而不是我现在建的一块 `Truck_MonitorScreen` —— 官方是
   **理智监控器 / 地点地图 / 活动监控器 / 任务列表 / 电脑 / 声音传感器监控器** 各自独立；
2. **地点地图有明确规格可照做**（玩家朝向/出口绿线/楼梯箭头/摄像头绿黄/运动传感器红线转绿/声音传感器橙色半径/左侧楼层箭头**不循环**）——
   这是本会话第一次拿到"可逐条实现"的官方 UI 规格；
3. 大厅的"00:00 计时器"也一并有了出处。
