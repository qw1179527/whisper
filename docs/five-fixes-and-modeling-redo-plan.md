## 三、建模精细重做（用户追加："把所有建模精细重做"）

现状问题（真机截图可见）：大厅是**纯 Box 拼的方盒子**（地板/墙/柱/桁架），货车是**纯 Cube 拼的长方体**，
都没有倒角、没有细节层、没有合适材质分层。这正是用户《补充说明》第 1、4 条反复强调的
「注重人物建模细节,场景建模合理与细节,内饰细节」「目前的**建模上色都不行**」。

**方案（按本仓既有资产管线规程）**：
1. 场景套件走 **`tools/gen-hall-kits.mjs`**（配方 `tools/lib/kit-hall.mjs` + Blender 构建器），
   **清单 `unity/Assets/Data/asset-manifest.json` 是唯一真源、禁止手工改**（记忆 #3）；
2. 每个套件要做到：正确尺度 + 倒角（Bevel）+ 合理 UV + PBR 材质分层（金属/水泥/木/织物）；
3. 货车单独做一套套件（车厢板/驾驶室/车轮/坡道/装备架/监控桌/座椅），替换现在的 Cube 拼装；
4. **每套件过 `gate-model.mjs`（M1–M11）**，并用 `blender_preview`/`blender_render` 出图人工核对外观；
5. 轴系契约：`gen-kits.mjs` 的 `export_yup=False` 是**正确**的（Y-up 语义自创作，见记忆中的轴系裁定），
   不要再"修"它。

⚠ 这一条是**多轮工作量**，不是一轮能完成；按"先场景、后货车、再道具"推进。

## 四、自由视角（P0，架构级）

**现状**：`MenuScene.UpdateBoardCamera(dt)` 每帧 `_cam.transform.position/rotation = …`，
在"自由位"与"看板位"之间插值 → 玩家**不能走、不能转头**。

**官方形态**：玩家在大厅**自由行走 + 自由转向**；"进操作界面"是**按空格/点板**触发的 UI 状态，
而不是"相机飞到板前"。

**改造方案**：
1. 新增 `LobbyPlayer`（或复用 `PlayerController`）：第一人称行走 + 自由环视
   （移动端：左半屏拖动=移动、右半屏拖动=转头；PC：WASD + 鼠标）；
2. `UpdateBoardCamera` **只在"操作视角"时接管**，且改为"**原地转向面对板**"（不再平移相机）；
   自由状态下**完全不写相机 transform**（交给 `LobbyPlayer`）；
3. 大厅碰撞体：官方要求"完整碰撞体、可自由行走"——`HallScene` 的墙/柱已有 BoxCollider，
   需补货车、货架、柜台等的碰撞体；
4. 验证判据（可测）：**两次不同方向的输入后，相机 yaw 不同且位置不同**。
