# 官方资料归档 ③：超自然现象 / 天气（2026-10-05 · 第 32 轮）

> 来源：`phasmophobia.su`（本环境可读）。

## 一、超自然现象（Ghost event）—— `/knowledge-base/gameplay/ghost-events`

**定义**：鬼在**不猎杀**、也**不进行普通物品互动**的情况下的显现。形态可为**完整人形 / 半透明剪影 / 影子 / 云团**，
常伴随**无需设备即可听见**的声响（低语、呻吟、唱歌）。用途：拍媒体、完成"目击现象"任务、观察行为、**通常扣理智**。

**与猎杀的区别**：现象中**接触不会死**、**出口门不锁**、**没有 grace**。

### 触发条件（鬼选一名调查区内玩家并传送过去）
- 最近的合适玩家在 **约 15 m 内且同层**（**区域外的玩家不算**；**另一层则取消本次尝试**）；
- 该房间允许出现现象；
- 不受鬼的类型限制（见下）；
- **Shade**：平均理智 < 100% 且**玩家不与它同房**；
- **Thaye**：衰老次数 **< 9**；
- 没有猴爪"困住鬼"的许愿状态。

### 形态
**完整 · 半透明 · 影子**（影子需要打光才看得清）。
- **Shade** 在现象中**常有 50% 概率为影子形态**；
- 普通鬼在**召唤阵 / 猴爪 / 音乐盒**触发时多为**完整形态**。

### 用诅咒道具强制现象
| 道具 | 效果 |
|---|---|
| **召唤阵** | 把鬼召到玩家处（非猎杀且理智足够时） |
| **猴爪**「看到鬼」 | 同召唤阵，但发生在**鬼当前位置** |
| **音乐盒** | **约 5 m 内且同层**时鬼走向盒子 |
| **塔罗「恶魔」** | 传送到最近玩家，**不限层与距离** |

### 四种现象类型（**带精确数值**）
| 类型 | 表现 | 理智 |
|---|---|---|
| **云团（airball）** | 一团烟云飞向玩家，**6–10 s**。追上目标 → 尖锐声 + **−10%** | 无云团者：**Oni、Kormos** |
| **静止（standing）** | 鬼原地站 **2–5 s** 并随机发声。**近距离注视它** → **−10%**（**Oni −20%**）；**不看则不掉** | 子类型：普通消失 / **消失后打碎灯泡** / **红光**（房间灯变红，需电闸开启；**Mara 不做**） |
| **唱歌（singing）** | 房间门关闭（无 UV、有 EMF）、灯灭、鬼原地唱。接触 → **−10%**（**Banshee 对其目标 −15%**、**Oni −20%**；未注视吓退 Oni → −10%）。女声约 **2–13 s**，男声约 **2–16 s** | **Shade 不做** |
| **移动（walking）** | 门关、灯灭，鬼以 **1.7 m/s** 走向目标 **6–10 s**（**与鬼的类型和速度设置无关**）。追上 → 声音 + **−10%**（**Oni −20%**） | **Kormos 不做** |

### 类型限制
| 限制 | 鬼 |
|---|---|
| 无云团 | **Oni、Kormos** |
| 无唱歌 | **Shade** |
| 无移动 | **Kormos** |
| 特殊规则 | **Banshee** 更常唱歌；**Shade** 与低理智相关；**Thaye** 衰老 9 次后不再出现现象 |

> ⚠ 云团**不是**"鬼的完整形态"：**不按显现那样改变温度**，也**不提供"鬼形态"类证据**；
> 互动产生的 **EMF 4 留在鬼的真实位置**，不在云团上。

## 二、天气（Weather）—— `/knowledge-base/gameplay/weather`（0.4.0 引入）

**8 种天气**：其中 7 种**等概率随机**，第 8 种是**可替换所选天气的稀有类型**。
天气分**四个温度组**（从暖到冷）：
`日出` → `晴 / 雾 / 血月` → `小雨 / 大雨 / 有风` → `雪`
⇒ **暖天气时鬼房的平均温度略高于冷天气**（影响"靠温度找鬼房"的判断）。
**室内效应减弱**：除罕见雷声外噪音被压低，雾与降水的视觉**不进入室内**。
例外：**Camp Woodwind 与 Maple Lodge Campsite 主要在户外**，天气影响显著。

| 天气 | 光照 | 可见度 | 噪声 | 温度 | 要点 |
|---|---|---|---|---|---|
| **日出 Sunrise** | 高 | 高 | 低 | **16°C** | 金色阳光，可改善部分区域照明；深蓝天无云 |
| **晴 Clear** | 差 | 高 | 低 | **13°C** | "标准"天气，无额外元素；环境昏暗、天空近黑 |
| **雾 Fog** | 中 | **差** | 低 | **13°C** | 浓雾限制可见度；室内散去，但**户外会影响夜视摄像机** |
| **血月 Blood Moon** | 中 | 高 | 中 | **13°C** | **鬼猎杀时快 15%** · **被动理智流失 +100%** · **合约奖励 +10%**；红天 + 小雨 |
| **小雨 Light Rain** | 中 | 高 | 中 | **8°C** | 中等雨声；**雨不会灭火** |
| **大雨 Heavy Rain** | 差 | 中 | **高** | **8°C** | 大雨与雷声形成高背景噪声；**打火机与非 III 级火源无法在雨中点燃**；**点燃的火源拿到户外会立即熄灭**；Maple Lodge / Camp Woodwind 在此天气**无法点火堆**；"让鬼吹灭蜡烛"目标在鬼房位于户外且无 III 级火源时**很难完成** |
| **有风 Windy** | 差 | 高 | 中 | **8°C** | 树木与风噪声大；云快速移动，其余类似晴天 |
| **雪 Snow** | 中 | 中 | 低 | **5°C** | 持续飘雪但不积雪；**轻度雾**；**低温会让呼吸白雾处处出现，掩盖鬼房的主要迹象之一** |
