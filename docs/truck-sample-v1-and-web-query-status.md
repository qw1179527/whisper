## 二、⚠ 渲染暴露的真实缺陷（比"不够细"更严重 —— 这批必须修）

`preview-iso.png` 是一张等轴测图，**看得出三处几何错误**：

| # | 缺陷 | 现象 | 修法 |
|---|---|---|---|
| **D1** | **驾驶室与厢体 Y 轴错位** | 渲染里驾驶室明显比厢体**高出一截且向后错开**，前脸悬空、与厢体不连续。根因：`cab_body` 中心 `y = CAB_Y0 + CAB_L*0.5 = 5.4+1.05 = 6.45`，而 `cab_windshield` 放在 `y = CAB_CY+CAB_L*0.5-0.05 = 7.45`（**越出驾驶室前脸 7.5 之外又反了方向**）；同时驾驶室地板 `CAB_Y0_FLOOR = FLOOR_H-0.35 = 0.6` 让驾驶室整体比厢体低 0.35 但高度还是 2.2 → 顶部比厢体顶（3.29）低得多，视觉上"矮一截" | 统一"驾驶室顶 = 厢体顶"：`cab` 中心 z = `FLOOR_H + BOX_H - CAB_H*0.5`；挡风玻璃贴前脸内侧 `y = CAB_Y0 + CAB_L - 0.03` |
| **D2** | **车轮装在车身外侧** | 渲染里四个轮子像"贴在车侧"，而不是藏在轮拱下。根因：`WX = CAB_W*0.5 - 0.06 = 1.04`，而厢体半宽 = 1.2 → 轮子在厢体投影**之内**但完全外露（没有轮拱、没有挡泥板） | 轮心内移（`WX = 0.95`）+ 加轮拱/挡泥板件遮住上半轮 |
| **D3** | **坡道脱体** | 左下角那块斜板与车体分离，看不出是"车尾坡道" | 坡道顶端贴在车尾板下沿（`y = 0`），绕 X 轴下倾 18°（`rotation_euler.x`），而不是平放地面 |

**另有观感问题**：整车是"两个白盒子"，缺乏商用车的必要轮廓特征（**轮拱、侧裙、后视镜、排气管、车厢侧板竖筋、车顶导流罩**）。
这些不需要高面数，但决定"看起来像不像一辆卡车"。

## 三、网页查询功能：**确认不可用**（给用户的正式回复）

用户要求"回复网页查询功能"。本轮我再次实测：
- `web_search` / `websearch`：**12+ 次查询（中/英、名词型/问句型、bing/bingcn）全部只返回"标题 + URL"列表，不返回正文**
- `web_fetch`：**不在工具集**（调用报 `unknown tool "web_fetch"`）

**结论：本环境无法读取网页正文。** 我能做到的只是**定位官方页面并把 URL 给你**：
