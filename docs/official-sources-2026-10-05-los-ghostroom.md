# 官方资料归档 ④：LoS / 鬼房（2026-10-05 · 第 32 轮）

> 来源：`phasmophobia.su`（本环境可读）。

## 一、视线接触 LoS —— `/knowledge-base/gameplay/line-of-sight`

**定义**：鬼能否"看见"玩家（即视线是否穿过地图几何）。猎杀中 LoS 是**开始追击与加速**的主要依据。
⚠ **不要与心跳混淆**：心跳取决于**距离 + 之间没有墙/门/地板**，但**家具常不挡心跳**（即使没有真正的 LoS）。

### 如何判定
- 玩家有 **6 个追踪点**（**3 个上部 + 3 个下部**，绑定相机）。**鬼看见任一组全部 3 点**即算有 LoS；
- 鬼视野 **360°**，**最远约 75 m**；
- **模型"头部"高度一致**（含爬行的鬼）；
- **阻挡 LoS**：**墙、地板、天花板、家具、玻璃门与窗、Prison 的牢房栅栏**；
- **不阻挡**：**扔在地上的小物品**；
- **普通玩家从柜子里探出头一般不给 LoS**（VR 因真实相机，风险更高）。

### 猎杀中的加速曲线
| 阶段 | 规则 |
|---|---|
| 保持 LoS | **每秒 +0.05× 基础速度**，**上限 1.65× 基础**（约 **13 s** 达到）。多数鬼基础 **1.7 m/s** → 最高约 **2.8 m/s** |
| 丢失侦测 | 速度**先保持**（在最后已知点附近搜索时），之后**每秒 −0.01× 基础**缓降 |
| 跨猎杀 | **加速不跨猎杀继承** |
| 圣木致盲 | **清零**已累积的 LoS 加速 |

### 打破常规的鬼（速度特例）
| 鬼 | 行为 |
|---|---|
| **Deogen** | **始终"看见"所有人**；速度由寻路距离决定，**不吃 LoS 加速** |
| **Revenant** | 无目标时**很慢**；**知道你在哪时约 3 m/s** |
| **Hantu** | 速度由**房间温度**决定，**无 LoS 加速** |
| **Thaye** | 速度按**年龄**固定 |
| **Jinn** | 有 LoS、距离 **> 3 m** 且**电闸开启**时，**固定 2.5 m/s** |
| **Raiju** | 在**活动电子设备半径内** 2.5 m/s |
| **Moroi** | 基础速度随**低理智**上升，另有常规 LoS 加速 |
| **Aswang** | **LoS 加速比常规更快** |

**Blood Moon：鬼整体速度 +15%。**

### 如何断开视线
- **绕拐角 / 关门**（**玻璃门也算**）；
- **不要从掩体里探头"看一眼"**；
- 记住：**同层的语音与开启的电子设备不需要 LoS 就能吸引鬼** —— 躲在掩体里要**关设备、别说话**。

### 非猎杀期
LoS 对部分能力与掉理智有影响（例如 **Phantom 显现时**）。
对新手的要点：猎杀中**"我看不见它" ≠ "我在黑暗中就安全"** —— **黑暗不影响鬼的视觉**。

## 二、鬼房（Favourite / Ghost room）—— `/knowledge-base/gameplay/ghost-room`

**定义**：鬼在本合约中"偏爱"的房间（或区域）。**大部分活动、鬼火（若为证据）、猎杀后返回**都绑定它。

> ⚠ **不要与"当前房间"混淆**：鬼可以游荡、给证据、甚至**不从最爱房间开始猎杀**。

### 最爱房间的作用
- **猎杀后传送回此处**；**十字架成功阻止后**也传送回此处；
- **鬼火（灵球）**住在最爱房间（**也是 Mimic 的弱点所在**）；
- **闹鬼魔镜**显示的正是**最爱房间**；
- 部分许愿/卡牌（**隐士**、"困住鬼"）与 **Yurei 的圣木**在非猎杀期会把鬼送回此处；
- **找到最爱房间不是合约目标**，但能大幅加速证据与媒体收集。

### 当前位置
- **互动与猎杀起手取决于当前位置**（**Twins 是例外**）；
- **通灵板**问"房间"回答的是**当前位置**，**不是**最爱房间 —— **即使你问的是"最爱"**；
- **自然现象**要求玩家在**鬼当前位置**的半径内；
- **游荡到别的房间本身不会改变最爱房间**；但 Mirage/Phantom 的传送类能力或 Banshee 的长距离游荡可把它带远，之后它仍可能回来。

### 换房的两段概率（**精确规则**）
发生"**长距离游荡**"到非最爱房间后，游戏掷**两次**：
1. **难度设置"换房"**：**无（Amateur/Intermediate）0%** · **低（Professional）33%** · **中（Nightmare）66%** · **高（Insanity）100%**；
2. **若第一次通过**，第二次概率 = **（100% − 平均理智）**。
   例：平均理智 80% → **20%** 概率换房。
⇒ **两次都成功**，新最爱房间 = 本次游荡到的房间。

**Goryo 自己不会换房**（即使 High），唯一例外是被猴爪许愿强制更换。

### 不能成为最爱房间的区域
部分地图的**走廊与辅助区域**不能被选为最爱房间：
- 那里**不会有鬼火**；**换房不会在该区域生效**；**猎杀后鬼不会传送到那里**；
- 但**仍可游荡与互动**；
- 具体清单依地图而定（**Prison 的主走廊**、**Sunny Meadows 的许多翼楼/走廊**等）。

### 实战建议（官方给玩家的）
- 用**鬼火 / 温度 / 活动**作为最爱房间的锚点，但要**确认鬼是否已经离开**；
- **Professional 及以上**、低理智时要**预期换房**；
- **十字架与圣木要留余量**：所谓"房间"可能是**走廊或很大的区域**。
