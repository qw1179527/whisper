> **方法与复现**：`tools/hall_props_threeview.py`（手机侧 Blender 5.0.1，无头）

> 复现命令：
> ```bash

> ```
> 前提：Blender 的 glTF 导入会**自动把 Y-up 转回 Z-up** ⇒ 渲染里的"上"就是**创作时的 +Z**。

## 二、从数据直接读出的**三类锚点语义**（这是填坑的答案）

**① 底面贴地型**（`bottom_at_z0 = true`）：`Barrel` / `IBeamColumn` / `LampIndustrial` / `PalletWood`
⇒ 原点在**底面中心**（X、Y 居中，Z=0 贴地）。
⇒ 摆放：`pos.y = 地面高度`，水平位置直接用原点。

**② 几何中心型**（偏移全 0）：`CrateWood` / `RackBeam`
⇒ 原点在**几何中心**。
⇒ 摆放：`pos.y = 地面高度 + size.z/2`（**不是**地面高度！按 ① 的方式摆会陷地一半）。

**③ 偏移型**（既非底面也非中心，**必须逐件处理**）：
- `RackUpright`：几何体整体偏 **+1.342m（Y）**、底面悬空 **4.2cm**。这是**最危险的一件** ——
  按原点摆会让货架立柱**偏出一米三**，正是"两次都没摆对"的直接机制。
- `IBeamColumn`：几何体偏 **+1.550m（Y）**（底面贴地，但水平上离原点 1.55m）。
- `LampIndustrial`：偏 **−0.425m（Y）**、**−0.538m（Z）**（灯体在原点下方与后方）。
- `DuctSection` / `PipeFlange`：Y 有小偏移（0.067 / 0.043），可忽略但记录在案。
- `ElectricPanel`：三个方向都有 1~2cm 偏移，可忽略。

## 三、可直接照做的摆放规则（把上面三类翻成代码）

```
摆放任何一件道具前，先取它**实测的 bbox**（不是它的原点）：
  baseY  = bbox.min.z          // 让底面落到目标地面
  centerX = (bbox.min.x+bbox.max.x)/2
  centerY = (bbox.min.y+bbox.max.y)/2
目标：把 (centerX, centerY, baseY) 对齐到设计位置。
即：pos = 设计位置 − (centerX, baseY, centerY)
```
**为什么按 bbox 而不是按原点**：本批 10 件里有 **6 件**的原点不在"底面中心"
（①型 4 件里有 3 件带水平偏移，②③型共 4 件另有偏移）。
**按原点摆 = 按一个各家不同的约定摆** —— 那正是这个坑反复出现的原因。

> ⚠ 三视图里还看到一件需注意的：`RackUpright` 的**正面视图是一条断续的细线** ——
> 因为它是 0.028m 厚的窄板，且**离原点 1.34m**，正交取景按 bbox 居中后它就落在画面一侧。
> 这与"截面在俯视图里不在中心"是同一件事。
