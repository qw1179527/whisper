# 第一部分：游戏建模系统

## 一、鬼魂模型 (Ghost Models)

### 1.1 模型数量与构成
游戏内鬼魂模型按性别区分，共有多套基础体型：

| 类别 | 数量 | 说明 |
|---|---|---|
| **男性体型** | **7 种** | 可套用多套贴图/外观 |
| **女性体型** | **3 种** | 可套用多套贴图/外观 |
| **儿童体型** | **1 种** | 仅一种，外观独特 |

> **关键机制**：鬼魂的类型、名称、性别、外观**均为随机生成**——同一外观可能是魂魄也可能是雾影；同一恶魔也可能是男性或女性。**因此无法通过模型或性别判断鬼魂身份**。

### 1.2 模型与技能的绑定关系
- **例外**：女妖 (Banshee) 自 v0.15.1.0 起**仅以女性形态出现**（名称与模型性别统一）；坎卜斯 (Krampus，活动鬼魂) 定义为男性。
- 除此之外，**"某种模型专属某种鬼魂"的说法均为误解**。
- 女妖、坎卜斯等少部分鬼魂有指定模型类型。

### 1.3 鬼魂显形形态 (Forms)
鬼魂在灵异事件/现身时可有多种表现形态：

| 形态 | 说明 |
|---|---|
| **实体形态 (Full)** | 完整可见的鬼魂模型 |
| **暗影形态 (Shadow)** | 纯黑剪影，无细节 |
| **半透明形态 (Translucent)** | 深色半透明轮廓 |
| **雾形/气雾 (Mist)** | 类似哈气/雾气（**仅赤鬼 Oni 不会使用此形态**） |
| **D.O.T.S 剪影** | 仅在 D.O.T.S 光阵中显现的轮廓 |

- **暗影 (Shade)** 的特殊性：在召唤阵、八音盒、猴爪事件中，仅暗影可呈**影子模型**（偏好影子形态）。
- 照片系统中可拍摄三种「鬼魂形态」：**实体 (Physical)、D.O.T.S、阴影 (Shadow)**。

### 1.4 鬼魂动画与表现细节
- **猎杀闪烁**：猎杀期间鬼魂反复显现/消失，频率随鬼魂类型而变：
  - 普通鬼魂：每 **0.3–1 秒**闪烁一次
  - **幻影 (Phantom)**：每 **1–2 秒**闪烁一次（更难拍照）
  - **赤鬼 (Oni)**：闪烁极少，几乎全程实体可见
- **行走与脚步**：鬼魂行走时产生脚步声；踩盐后会留下脚印（魅影除外）。
- **发声**：至少 **8 种男性音效**、**5 种女性音效**，包含死亡喉音、呻吟、呼吸声、低吼、哼唱、咳嗽、哭泣、童笑等。

### 1.5 玩家模型与角色重做
- **玩家角色重做 (Player Character Overhaul)**：2025 路线图公布的重大更新，扩展角色自定义——不同服装与外观改装，提升沉浸感。
- **声望 (Prestige) 专属解锁**：新玩家模型上线后，玩家可用游戏内 $ 购买**声望相关专属道具**，如角色配饰或新外套。

# 第二部分：画质与图形系统

## 二、引擎与渲染基础

| 项目 | 说明 |
|---|---|
| **引擎** | Unity 2022 |
| **视角** | 第一人称（垂直 FOV） |
| **物理更新率** | 物品与玩家物理**锁定 60 Hz** |
| **升级方向** | 官方持续升级 Unity 引擎版本，为「恐怖 2.0」与 1.0 做准备 |

> **重要技术限制**：自约 v0.11.0 起，物品物理与玩家移动的更新率被**锁定为每秒 60 次**。当渲染帧率超过 60 FPS 并在高于 60 Hz 的显示器上观看时，会出现**横向移动时的画面抖动 (jitter)**，甚至引发晕动感。

## 三、视频设置选项详解

### 3.1 显示设置
| 设置项 | 可选值 / 说明 |
|---|---|
| **显示模式** | 独占全屏 / 无边框窗口全屏 / 窗口化 |
| **分辨率** | 支持宽屏、超宽屏、4K UHD、多显示器 |
| **垂直同步 (VSync)** | 开（限帧至刷新率，默认开启，**VR 模式下不显示**）/ 关（降低输入延迟，但可能画面撕裂） |
| **帧率** | 支持 60 FPS 与 120+ FPS |
| **FOV（视野）** | **60°–90°**（默认 70°，使用垂直 FOV） |

### 3.2 画质设置
| 设置项 | 可选值 / 说明 |
|---|---|
| **图形质量 (Graphics Quality)** | 预设档位或**自定义 (Custom)** |
| **抗锯齿 (AA)** | **FXAA / SMAA / MSAA (2x–8x) / TAA** |
| **纹理分辨率 (Texture Resolution)** | 低 / 中 / 高（高需约 4–6 GB VRAM） |
| **阴影质量 (Shadow Quality)** | 低 / 中 / 高（性能开销最大项） |
| **阴影分辨率 (Shadow Resolution)** | 半 / 低 / 高 |
| **各向异性过滤 (AF)** | 开/关，通常 4x / 8x / 16x |
| **环境光遮蔽 (SSAO)** | 低 / 关（关闭后暗角更清晰、提升帧率） |
| **体积光照 (Volumetric Lighting)** | 开/关（**关闭可获最大性能提升**，尤其是监狱、精神病院等大图） |
| **雾质量 (Fog Quality)** | 影响氛围真实感 |
| **高保真升频** | **FSR 1** |
| **光线追踪 (Ray Tracing)** | 支持（视硬件） |
| **HDR** | 视显示设备 |

### 3.3 后处理效果（多不适用于 VR）
| 效果 | 说明 |
|---|---|
| **泛光 (Bloom)** | 镜头光晕，关闭可减少蹲鬼时的视线干扰 |
| **色差 (Chromatic Aberration)** | 边缘彩边，关闭可锐化画面 |
| **胶片颗粒 (Film Grain)** | 电影质感颗粒 |
| **眼适应 (Eye Adaption)** | 模拟瞳孔对明暗变化的调节，影响暗处可见度 |
| **亮度 (Brightness)** | 影响黑暗场景的可见性 |
| **色盲模式 (Color Blind Mode)** | 支持 |

### 3.4 性能优化推荐配置（社区实测）
| 设置项 | 推荐值 | 理由 |
|---|---|---|
| 显示模式 | **独占全屏** | 降低输入延迟，优先分配 GPU 资源 |
| 分辨率 | 显示器原生（弱卡降至 1080p / 1600×900） | 平衡清晰度与性能 |
| 图形质量 | 自定义 | 精细控制 |
| 抗锯齿 | **SMAA** | 干净边缘且性能开销低于 TAA |
| 纹理分辨率 | 高（≥6 GB VRAM） | 减少墙面/门贴图模糊 |
| 阴影质量 | **中** | 高阴影在明亮房间极耗性能 |
| 阴影分辨率 | 半 | 同上 |
| 体积光照 | **关** | 大图最大帧率提升 |
| 环境光遮蔽 | 低 / 关 | 提升帧率 |
| 泛光 / 色差 | **关** | 减少视觉干扰 |
| 各向异性过滤 | 16x | 现代 GPU 开销极小 |
| 垂直同步 | **关** | 最小化输入延迟 |

> **重要提示**：官方建议**将帧率锁定在 60 FPS** 并测试 VSync 开关，因为物理 tick 率被锁定以保持整体性能。

## 四、硬件与稳定性说明

### 4.1 系统需求
| 项目 | 需求 |
|---|---|
| **最低配置** | 面向 **VR**；非 VR 下更低配置也可能运行 |
| **参考最低** | Windows 10、Intel i5-4590 / AMD FX 8350、8 GB RAM、15 GB 硬盘、GTX 970 / R9 290 |
| **VR 推荐** | Intel i5-10600K（6 核）、**16 GB RAM**、**RTX 3060** 或同级 AMD GPU |

### 4.2 已知性能问题
- **VR 默认启动问题**：游戏默认尝试以 VR 模式启动，可能启动 VR 中间件并重配音频；可通过 Steam 第二启动项绕过。
- **高 GPU 占用与过热**：2024–2025 年玩家报告未限帧、高画质、特定地图下 GPU 占用高、发热甚至崩溃关机。
- **CCTV/摄影机降帧**：使用游戏内视频或摄影机时可能导致 FPS 下降。
- **建议**：通过 NVIDIA/AMD 控制面板或游戏内 VSync 限制帧率、降低画质、检查散热。

### 4.3 音频与本地化
| 项目 | 说明 |
|---|---|
| **音量控制** | 仅主音量（Master Volume） |
| **环绕声** | 最高 7.1 |
| **字幕 / 隐藏式字幕** | 支持 |
| **支持语言** | 含**简体中文、繁体中文**、英语、日语、韩语、法语、德语、西班牙语、俄语等约 25 种 |
| **语音识别** | 支持（部分设备切换可能影响语音识别） |

# 第三部分：UI 界面系统

## 五、UI 整体演进

### 5.1 更新历史
| 版本 | UI 相关变化 |

### 5.2 v0.13 主菜单重做要点
- **全新主菜单 UI**（保留原有功能）
- 创建房间时可设置：
  - **游玩风格 (Playstyle)**：休闲 (Casual)、硬核 (Hardcore)、角色扮演 (Roleplay)
  - **硬件偏好**：需要 VR / 需要麦克风
- **房间浏览器筛选**：可按难度、硬件、游玩风格筛选

- 支持手柄 UI 反馈与自动瞄准
- 可返回赛后结算界面
- 自定义难度**可重命名**
- **Twitch Drops** 已上线

## 六、主菜单结构

### 6.1 主要菜单项
| 界面 | 功能 |
|---|---|
| **主页 (Home)** | 创建/加入房间、选择地图与难度 |
| **商店 (Shop)** | 购买与升级装备 |
| **日志 (Journal)** | 查看证据、鬼魂信息、任务、媒体 |
| **自定义难度 (Custom Difficulty)** | 等级 50 解锁，自定义各项参数 |
| **设置 (Settings)** | 图形、音频、控制、语言等 |
| **奖杯陈列柜 (Trophy Cabinet)** | 展示成就与活动奖杯 |

### 6.2 房间创建/大厅
- **游玩风格**：休闲 / 硬核 / 角色扮演
- **硬件要求**：VR Required / Microphone Required
- **地图选择**：小/中/大各类地图
- **难度**：业余 / 中级 / 专家 / 噩梦 / 疯狂 / 自定义
- **房间浏览器**：显示难度（或自定义倍数）、地图、硬件、风格，可筛选

### 6.3 辅助功能与自定义（v0.9.5.0 起）
- **玩家专属颜色自定义**：主菜单贴纸、商店界面、卡车理智屏、玩家光标
- **光标自定义**：形状、颜色、不透明度、大小
- 高亮物体时的附加选项
- **VR 限制**：VR 玩家仅可调整高亮光标的颜色与不透明度

## 七、日志系统 (Journal)

### 7.1 日志标签页
| 标签页 | 内容 |
|---|---|
| **证据 / 鬼魂 (Evidence/Ghosts)** | 勾选证据、排除鬼魂类型；V0.15.1.0 起鬼魂类型按字母顺序排列（仅英文版本） |
| **任务 (Tasks)** | 本局可选目标 |
| **媒体 (Media)** ← v0.13 新增 | 替代原 Photos 标签，分三页：**照片 / 视频 / 声音录制** |
| **备注 / 其他** | 玩家笔记等 |

### 7.2 媒体标签页（v0.13 Chronicle）
- 原 Photos 标签 → 全新 **Media 标签**
- 三个子页：
  - **照片 (Photos)**：最多 5 张
  - **视频 (Videos)**：最多 5 段
  - **声音录制 (Sound Recordings)**：最多 3 段
- **独特/重复标记**：首次捕获标为 Unique，重复标为 Duplicate
- 单局可删除 **3 件**媒体
- 声音录制可在日志中**回放**

### 7.3 日志可读性优化
- **降低日志亮度**（v0.9.5.0）：减轻刺眼，改善长时间查看体验

## 八、卡车（车内）界面系统

### 8.1 卡车设备界面
| 设备 | 界面功能 |
|---|---|
| **理智监视器 (Sanity Monitor)** | 显示每名玩家及团队平均理智值 |
| **现场地图 (Site Map)** | 显示建筑布局，标记传感器位置 |
| **目标板 (Objective Board)** | 追踪合同目标 |
| **电脑 (Computer)** | 管理设置与目标 |
| **声音监视器 (Sound Monitor)** | 接收声音传感器信号 |
| **现场活动监视器 (Site Activity Monitor)** | 追踪整体鬼魂活动强度（1–10 级） |

### 8.2 CCTV 系统（v0.13 重做）
- 界面分为三类：**CCTV 摄像头 / 摄影机 (Video Cameras) / 头戴摄影机 (Head Cameras)**
- **最多同时查看 5 路实时画面**（旧版本更少）
- **可直接从车内录制视频媒体**
- 修复：同时开启多个监控摄像头查看监控屏可能导致断线的问题（v0.15.1.0）

### 8.3 活动监视器机制
- 猎杀期间活动显示 **10 级**
- 但 **10 级不一定代表正在猎杀**，且活动等级不直接指示猎杀概率
