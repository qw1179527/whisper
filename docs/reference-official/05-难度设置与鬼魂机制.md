# 一、难度系统总览

《恐鬼症》的难度**不只是「鬼更凶」**，而是一整套**乘算的规则开关组**。选定难度后，会同时改变四类东西：

| 维度 | 难度会影响什么 |
|---|---|
| **玩家侧** | 初始理智、理智流失速度、醒脑丸恢复量、玩家移速、能否奔跑、手电禁用、死亡赔偿比例 |
| **鬼魂侧** | 鬼魂移速、游荡频率、换鬼房概率、互动频率、事件频率、猎杀徘徊期、猎杀时长、击杀延长、给出的证据数 |
| **合约侧** | 部署期时长、天气、开局敞开的门数量、躲藏点数量、电闸初始状态、监视屏可用性、诅咒之物数量 |
| **奖励侧** | 金钱倍率、经验倍率、赔偿比例（难度越高奖励越高，安全网越少） |

**核心设计逻辑**：难度是一条**「时间×信息×容错」三重递减曲线**——
- **时间**：部署期从 5 分钟 → 0 秒；理智流失从 100% → 200%。
- **信息**：证据从 3 条 → 2 条 → 1 条；任务板不再显示鬼魂回应类型。
- **容错**：赔偿从 50% → 0%；躲藏点从「极高」 → 「低」；监视屏从可用 → 损坏、诅咒之物从 1 个 → 0 个。

而**奖励倍率**（金钱/经验）则沿同一条曲线**反向递增**：×1 → ×2 → ×3 → ×4 → ×6。

# 二、五档预设难度详解

## 2.1 业余（Amateur）— 新手教学场

> **官方描述**：推荐新猎鬼师使用的难度。一般金钱和经验奖励。

| 项目 | 数值 |
|---|---|
| 解锁等级 | 无（默认可用） |
| 金钱 / 经验倍率 | ×1 |
| 部署期 | **5 分钟（300 秒）** |
| 理智流失速度 | 100%（标准） |
| 醒脑丸恢复 | **40%** |
| 死亡赔偿 | **丢失物品价值的 50%** |
| 电闸开局 | **开** |
| 躲藏点数量 | 极高 |
| 诅咒之物数量 | 1 |
| 监视屏（理智/活动） | 均可使用 |
| 猎杀徘徊期 | 5 秒 |
| 猎杀时长 | 低 |

**特点**：所有门开局关闭（可据「哪扇门开了」反推鬼房）；躲藏点全开；黑暗中理智几乎不掉，容许慢慢探索。**最适合学习证据系统、地图布局与基本操作**。

## 2.2 中级（Intermediate）— 标准体验

> **官方描述**：标准的猎鬼体验。10 级解锁。

| 项目 | 数值 |
|---|---|
| 解锁等级 | **10 级** |
| 金钱 / 经验倍率 | **×2** |
| 部署期 | 2 分钟（120 秒） |
| 理智流失速度 | **150%（1.5 倍）** |
| 醒脑丸恢复 | 35% |
| 死亡赔偿 | 25% |
| 电闸开局 | **关** |
| 开局敞开的门 | 低（少数门已开） |
| 躲藏点数量 | 高（一些被堵） |
| 诅咒之物数量 | 1 |
| 猎杀徘徊期 | 4 秒 |
| 猎杀时长 | 中 |

**特点**：开始出现「需要自己开电闸」的核心循环；黑暗中理智流失加快，逼玩家点灯。**平衡度最佳、学习压力可控的过渡档**。

## 2.3 专家（Professional）— 资深门槛（民间常写「专业」）

> **官方描述**：为资深猎鬼师提供的难度。20 级解锁。

| 项目 | 数值 |
|---|---|
| 解锁等级 | **20 级** |
| 金钱 / 经验倍率 | **×3** |
| 部署期 | **无（0 秒）** |
| 理智流失速度 | **200%（2 倍）** |
| 醒脑丸恢复 | 30% |
| 死亡赔偿 | **无（0%）** |
| 电闸开局 | 关 |
| 鬼房变动 | **低概率** |
| 任务板 | **不显示鬼魂回应类型** |
| 躲藏点数量 | 中（更少） |
| 猎杀徘徊期 | 3 秒 |
| 猎杀时长 | 高 |

**特点**：进出即可能猎杀，**信息仍完整（3 条证据）但生存容错大幅收紧**。公认的**「标准难度」与长期收益档**——保留完整证据系统的同时给出 ×3 收益。适合已能快速找到鬼房、规划躲藏点的玩家。

## 2.4 噩梦（Nightmare）— 知识检验场

> **官方描述**：为顶尖猎鬼师提供的试炼。30 级解锁。

| 项目 | 数值 |
|---|---|
| 解锁等级 | **30 级** |
| 金钱 / 经验倍率 | **×4** |
| 部署期 | 无 |
| 理智流失速度 | 200% |
| 醒脑丸恢复 | 25% |
| 死亡赔偿 | 无 |
| 电闸开局 | 关 |
| 鬼房变动 | **中概率** |
| **给出的证据数** | **2 条（隐藏 1 条）** |
| 监视屏 | **理智屏与活动屏均损坏** |
| 击杀延长猎杀 | **有（每次击杀延长猎杀）** |
| 躲藏点数量 | 低（几乎无） |
| 猎杀徘徊期 | 2 秒 |
| 猎杀时长 | 高 |

**特点**：**首次隐藏证据**，必须靠**行为与二次线索**反推鬼魂（见第八章识别要点）。监视屏损坏意味着**无法直接读团队理智与活动强度**，只能靠装备（EMF、温度、灵球等）与声音判断。**真正的「知识检验」难度**。

## 2.5 疯狂（Insanity）— 最高预设

> **官方描述**：觉得自己很勇敢？这些鬼可不好惹…… 40 级解锁。

| 项目 | 数值 |
|---|---|
| 解锁等级 | **40 级** |
| 金钱 / 经验倍率 | **×6** |
| 初始理智 | **75%（并非满值）** |
| 部署期 | 无 |
| 理智流失速度 | 200% |
| 醒脑丸恢复 | **20%** |
| 死亡赔偿 | 无 |
| 电闸开局 | 关 |
| 鬼房变动 | **高概率（经常更换鬼房）** |
| **给出的证据数** | **1 条（隐藏 2 条）** |
| **诅咒之物数量** | **0（完全没有）** |
| 监视屏 | 均损坏 |
| 击杀延长猎杀 | 有（时长更长） |
| 躲藏点数量 | 低（几乎无） |
| 猎杀徘徊期 | **2 秒（最短）** |
| 猎杀时长 | 高（更长） |

**特点**：**只有 1 条证据 + 没有诅咒之物 + 初始理智仅 75%**。这是「靠自己脑子和胆量」的极限预设——需要极强的地图知识、冷静决策，以及从速度/闪烁/行为反推鬼魂的能力。**×6 为标准预设最高收益，但不可作为常规升级路线，更像挑战场**。

# 四、自定义难度（Custom）

- **解锁**：**50 级**。可保存 **3 套**自定义难度配置。
- **倍率上限**：自定义倍率**超过 ×15 会被强制钳制为 ×15**。
- **错误的识别惩罚**：若**最终识别鬼魂类型错误**，该局合约倍率会**降到下一档预设难度（向下取整）**。例如你设的是 ×5，识别错了就按 ×4（噩梦档）结算。
- **零倍率合约**：自 v0.19.0.0 起，**×0 的自定义合约不再计入成就/挑战进度**；想拿成就请务必开到有效倍率。

**自定义三大类参数**（对应上表所有「自定义范围」列）：

1. **玩家设置**：初始理智、醒脑丸、理智流失、奔跑、移速、手电、死亡丢失物品。
2. **鬼魂设置**：移速、游荡频率、换鬼房、互动数、事件频率、友善的鬼、徘徊期、猎杀时长、击杀延长、给出证据、指纹几率/时长。
3. **合约参数**：部署期、天气、开局敞开的门、躲藏点、两个监视屏、电闸初始状态、电闸是否显示、诅咒之物数量与具体种类。

# 五、挑战模式（Challenge Mode）

- **形式**：**每周轮换**的独特合约，带**定制的免费装备装载**与额外的难度调整。目前共有 **26 种挑战模式**在轮换池中。
- **奖励**：完成每周挑战模式给予 **$5,000 和 5,000 XP**。
- **装备**：挑战模式通常**提供免费固定装备**，不带自己的装备，因此死亡损失较小。
- **注意**：挑战模式**不生成诅咒之物**（见下方易错点）。

# 六、天启挑战（Apocalypse I–III）

《恐鬼症》的最高难度考验。三档均为**单人、晴草甸精神病院（Sunny Meadows Mental Institution，完整版）**。

| 档位 | 奖杯 | 所需倍率 | 徽章 |
|---|---|---|---|
| **天启 I** | 青铜 | **×6 或以上** | Apocalypse Adept |
| **天启 II** | 白银 | **×10 或以上** | Apocalypse Master |
| **天启 III** | 黄金 | **×15** | Apocalypse Legend |

**一局内必须同时完成 5 项**，且必须在**单人模式**下、**活着撤离**：

1. 正确识别鬼魂类型
2. 完成全部 3 个可选目标
3. 拍下/录制**鬼魂媒体**（自 v0.18.0.0 起，照片/视频/录音**任意一种媒体均可**，不再只限照片）
4. （隐含）存活并成功撤离
5. 倍率达标（×6 / ×10 / ×15）

> 完成更高档会**自动解锁其下所有档**的奖杯与徽章。奖杯展示在大厅，倍率提高时自动升级。

**天启 III（黄金，×15）推荐自定义配置**（也是最简路线——直接用内置 Apocalypse III 预设即为 ×15）：

| 类别 | 设置 |
|---|---|
| **玩家** | 初始理智 0%、醒脑丸恢复 0%、玩家移速 **50%**、奔跑关闭、手电禁用、理智流失 200% |
| **鬼魂** | 鬼魂移速 150%、徘徊期 **0 秒**、猎杀时长 高、给出证据 **0**、游荡 高、换鬼房 高、活动 低、击杀延长 高 |
| **合约** | 地图 Sunny Meadows、部署期 **0 秒**、电闸损坏、躲藏点 0、开局敞开的门 高、卡车监视屏禁用 |

> **两个致命细节**：
> 1. 玩家移速必须设 **50%**（不是 75%）——75% 是「天启 II」的值，最终只有 ×14.60，只够白银。
> 2. 部署期必须设 **0 秒**——若留在默认 300 秒，奖励会被**硬钳制为 ×1.00**，该局**完全不算数**。

> **实际打法要点**：由于 0 理智 + 0 秒徘徊期，进场即可能猎杀。主流思路是**刷新合约直到拿到合适的目标 + 选雾影（Deogen）**——雾影在 2.5 米内会降到约 0.4 米/秒，可绕着礼拜堂长椅无限循环，即使 50% 玩家移速也甩得开 150% 的鬼。用熏香致盲的窗口拍下鬼魂媒体、日志里锁识别、回卡车撤离。（雾影需房主账号达到 P0 30 级才会出现。）

# 七、难度如何改写鬼魂机制

难度不是「加个血条」，而是**逐项改写猎杀与行为机制的参数**。以下把第三章的表格翻译成**机制语言**。

## 7.1 部署期（Setup Phase）→ 决定「多久后才可能被猎杀」

| 难度 | 部署期 |
|---|---|
| 业余 | 5 分钟 |
| 中级 | 2 分钟 |
| 专家 / 噩梦 / 疯狂 | **无** |
| 自定义 | 0 – 300 秒 |

- 部署期内**鬼魂无法猎杀**，但仍可互动、事件、给证据。
- **使用任何诅咒之物会立即提前结束部署期**。
- 部署期从**推开房屋大门的那一刻**开始计时，玩家在屋外等待**不会**顺延。

## 7.2 猎杀时长（Hunt Duration）→ 按难度与地图大小决定

| 难度（猎杀时长档） | 小型地图 | 中型地图 | 大型地图 |
|---|---|---|---|
| 低（业余） | 15 秒 | 30 秒 | 40 秒 |
| 中（中级） | 20 秒 | 40 秒 | 50 秒 |
| 高（专家/噩梦/疯狂） | **30 秒** | **50 秒** | **1 分钟** |

- **诅咒猎杀**时长统一**再加 20 秒**，且**之后的普通猎杀也额外延长 20 秒**。
- **击杀延长**：噩梦/疯狂（及自定义「低/中/高」）下，**每杀死一名玩家会延长猎杀时间**。噩梦基础为 **+15 秒/杀**。

## 7.3 猎杀徘徊期（Grace Period）→ 反应窗口

| 难度 | 徘徊期 |
|---|---|
| 业余 | 5 秒 |
| 中级 | 4 秒 |
| 专家 | 3 秒 |
| 噩梦 / 疯狂 | 2 秒 |
| **诅咒猎杀（所有难度）** | **1 秒** |
| 自定义 | 0 – 6 秒 |

徘徊期内鬼魂**隐身、静止、不探测、不杀人**，所有出口门已上锁。

## 7.4 猎杀冷却（Cooldown）

- 普通猎杀结束后**最少 25 秒**冷却（**恶魔为 20 秒**）才能再次发动。
- **诅咒猎杀不受冷却限制**，可紧接普通猎杀发动。
- 冷却结束**通常不会立即再次猎杀**（仍需满足理智阈值，且有概率判定）。
- 诅咒猎杀若因区域无人被取消，**不计入**冷却计时。

## 7.5 证据数量 → 决定「信息量」

- **3 条**（业余/中级/专家）→ 常规推理即可锁定鬼魂。
- **2 条**（噩梦）→ 需行为反推。
- **1 条**（疯狂）→ 极限推理。
- **0 条**（天启 III/自定义）→ 纯行为与排除法。

证据被隐藏时，游戏会**从该鬼魂的 3 条证据中随机隐藏 1（或 2）条**，保留其余。因此**某条证据没出**≠「不是这个鬼」。

## 7.6 理智流失与猎杀阈值（Sanity）

- 理智流失速度：业余 100%、中级 150%、专家/噩梦/疯狂 **200%**。
- 疯狂难度**初始理智只有 75%**。
- 猎杀由**全体存活玩家的平均理智**决定：**平均理智 ≤ 阈值时，每隔几秒按概率判定是否猎杀**，理智越低概率越高。
- **黑暗加速流失**：关闭电闸、长时间处于无光区域会加速平均理智下滑，从而**提前到达猎杀阈值**。
- 死亡玩家**不计入**平均理智。

## 7.7 鬼房变动 / 游荡 / 互动 / 事件

| 参数 | 难度影响 |
|---|---|
| **换鬼房** | 专家「低」、噩梦「中」、疯狂「高」——鬼会整体迁移房间，导致旧鬼房证据失效，**必须重新定位** |
| **游荡频率** | 高级难度更频繁游荡，鬼更可能离开鬼房 |
| **互动数** | 难度越高互动越少（专家/噩梦/疯狂为「低」）——**证据更难刷出** |
| **事件频率** | 难度越高事件越频繁（噩梦/疯狂为「高」）——**显形/事件多，理智掉得更快** |

## 7.8 监视屏 / 电闸 / 躲藏点 / 诅咒之物

- **监视屏**：噩梦/疯狂下**理智屏与活动屏损坏**，无法直接读团队理智与活动强度。
- **电闸**：中级起**开局关闭**；噩梦/疯狂电线位置也不再显示在图屏上。
- **躲藏点**：从「极高」→「低」，噩梦/疯狂**几乎没有躲藏点**，只能「绕圈跑位（looping）」。
- **诅咒之物**：疯狂/自定义可设 **0 个**；数量与种类在自定义里可精确指定。

# 九、按难度分层的实战策略

## 9.1 业余 → 中级：学会「流程」

- 先开电闸、找到鬼房、铺证据（EMF/温度/灵球/通灵盒/鬼写/D.O.T.S/指纹）。
- 中级起**黑暗中理智掉得快**，进屋先找电闸点灯。
- 中级门有些是开的，**不能再凭「哪扇门开了」判断鬼房**。

## 9.2 中级 → 专家：学会「效率」

- **无部署期**，进门前先看好躲藏点与逃跑路线（如已知）。
- 快速定位鬼房 + 高效铺证据是核心；死亡无赔偿，**装备成本要算**。
- 鬼房开始有小概率变动，证据断续时应怀疑换房。

## 9.3 专家 → 噩梦：学会「反推」

- **只有 2 条证据**，必须靠**行为 + 阈值 + 特殊能力**补足：
  - 幻妖 → 变形模型、双轮廓指纹。
  - 鬼婴 → 声音距离更短、超自然声音更频繁。
  - 寒魔 → 冷房间更快、呼气可见。
  - 御灵 → 灵球只在相机中可见、几乎不出鬼房。
  - 亡魂 → 未检测时极慢、检测后直冲 3 米/秒。
  - 魔洛伊 → 理智越低越快。
- 监视屏损坏，用 EMF/温度/声音替代读理智。

## 9.4 疯狂 / 天启：学会「极限」

- **1 条证据甚至 0 条**：靠**速度、闪烁频率、脚步节奏、特殊行为**锁定鬼魂。
- **无诅咒之物**：没有塔罗牌/通灵板等强制手段，只能常规流程。
- **高概率换房**：证据一旦停摆，立刻重新搜索。
- **初始理智低 + 200% 流失**：进图即可能猎杀，**先定逃跑路线再铺设备**。
- 常用生存技巧：**绕圈跑位（looping）**、熏香致盲窗口、猴子玩偶（自定义有诅咒之物时）。

# 十、常见问题与易错点

**Q1：说话或骂脏话会提高猎杀概率吗？**
❌ 不会。这是常见误解。**妖怪（Yokai）例外**：玩家在它同房说话会让阈值升高（80%），但那是因为它在**听你说话**，而非「骂脏话」本身有效果。

**Q2：活动强度显示 10 级＝正在猎杀吗？**
❌ 不一定。猎杀时活动强度**总是 10 级**，但 10 级**不一定代表猎杀**。活动强度本身不影响猎杀概率。

**Q3：某条证据一直没出，是不是就不是这个鬼？**
❌ 在高难度**不成立**。噩梦隐藏 1 条、疯狂隐藏 2 条证据，被隐藏的证据**永远不会以常规方式出现**。要结合行为判断。

**Q4：难度越高鬼跑得越快吗？**
预设难度下**鬼魂移速默认都是 100%**（只有**自定义**可调到 50%–150%）。高难度的「快」主要来自**猎杀时长更长、徘徊期更短、冷却与阈值更凶**，而非基础移速。天启 III 才是把鬼魂移速设为 **150%**。

**Q5：挑战模式会出诅咒之物吗？**
❌ 不会。**挑战模式不生成诅咒之物**。疯狂预设的诅咒之物数量也是 **0**。

**Q6：自定义设置很复杂，会白刷吗？**
注意两点：①倍率 >×15 会被钳制为 ×15；②**识别错误会把倍率降到下一档预设**；③×0 合约不计成就。避坑就能正常收益。

**Q7：难度之间如何选择？**
- 学流程 → **业余**
- 早期养成 → **中级**
- 长期主刷（信息完整 + ×3） → **专家**
- 知识检验（2 证据） → **噩梦**
- 极限挑战（1 证据、无诅咒之物） → **疯狂**
- 拿成就/徽章 → **天启 I–III**
