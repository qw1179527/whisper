# 第一部分：核心机制

## 一、游戏目标与调查流程

玩家扮演灵异调查小队成员，进入被灵异现象骚扰的地点，使用专业设备收集证据、判定鬼魂类型，并安全撤离。合同结束后按完成情况结算金钱与经验值。

**标准调查流程：**
1. 进入地点（打开前门即激活鬼魂）
2. 定位鬼房（温度计 / EMF / 抛物面麦克风）
3. 收集 3 条证据（噩梦 2 条 / 疯狂 1 条）
4. 若证据不足，测试鬼魂**行为特征**辅助判断
5. 完成可选目标、拍摄媒体
6. 撤离并提交鬼魂类型

## 二、鬼魂常规行为机制

### 2.1 鬼魂状态（State）循环
| 状态 | 说明 |
|---|---|
| **Idling 静止** | 原地停留 2–6 秒 |
| **Roaming 游荡** | 在球形范围内随机选点移动。短程 ≤3 米，长程 ≤12 米 |
| **Favourite Room 鬼房** | 返回其偏爱房间 |
| **Interaction 互动** | 与附近物体互动（抛物、开关门窗等） |
| **Fuse Box 电闸** | 开关电闸 |
| **Ghost Event 灵异事件** | 触发显形/事件 |
| **Ability 特殊能力** | 使用专属能力（若有） |
| **Hunt 猎杀** | 发起猎杀 |
| **D.O.T.S** | 拥有 D.O.T.S 证据的鬼魂会偶尔进入此状态 |

**游荡频率（难度设置）：**
- 低：90% 短程 / 10% 长程
- 中：80% 短程 / 20% 长程
- 高：70% 短程 / 30% 长程

> 除梦魇 (Mare) 与女妖 (Banshee) 外，鬼魂**不能在鬼房之外发起长程游荡**。

### 2.2 电子干扰半径
- 普通鬼魂显形或猎杀时，**10 米**内的电子设备（手电、全局语音等）失灵。
- **雷魂 (Raiju)**：干扰半径为 **15 米**。
- 房间灯光同样在相同距离内闪烁。

### 2.3 声音机制
- 灵异事件/猎杀时鬼魂会发出声音，玩家最远可在 **20 米**听到。
- 鬼魂每 **80–127 秒**发出一次「超自然声音」（呻吟/笑声/低语），只能通过**抛物面麦克风**或**声音记录仪**听到。
- **鬼婴 (Myling)** 超自然声音间隔更短：**64–127 秒**。
- 鬼魂模型与性别相关，但**模型不代表鬼魂类型**。

### 2.4 激活规则
- 未打开前门进入建筑时，鬼魂**未激活**：无法互动、事件、猎杀（但灵球等部分证据仍可获得）。
- 但**诅咒道具仍可强制触发诅咒猎杀**。
- 鬼魂**无法离开调查区域**，即使大门敞开。

# 第二部分：猎杀机制详解

## 三、猎杀基本规则

### 3.1 准备工作期 (Setup Phase)
猎杀无法在准备期内发生：

| 难度 | 准备期时长 |
|---|---|
| 业余 | 5 分钟 |
| 中级 | 2 分钟 |
| 专家 / 噩梦 / 疯狂 | 无准备期 |

> 使用诅咒道具可**提前结束**准备期。

### 3.2 猎杀冷却
- 普通猎杀结束后，最少 **25 秒** 冷却（恶魔 Demon 为 **20 秒**）才能再次发起。
- 冷却**不影响**诅咒猎杀的发动。

### 3.3 猎杀前置条件
- 调查区域内**至少有一名存活玩家**。
- 团队**平均理智值**低于鬼魂的猎杀阈值（见下表）。
- 平均理智仅计算**存活玩家**，死者不计入。
- **说话或骂脏话不会提高猎杀概率**（此为常见误解）。

### 3.4 猎杀宽限期 (Grace Period)
猎杀开始到鬼魂开始追击之间存在宽限期，期间鬼魂**不可见、静止、无法探测玩家**，出口已上锁：

| 难度 / 类型 | 宽限期 |
|---|---|
| 业余 | 5 秒 |
| 中级 | 4 秒 |
| 专家 | 3 秒 |
| 噩梦 | 2 秒 |
| 疯狂 | 2 秒 |
| **诅咒猎杀** | **1 秒** |
| 自定义 | 0–5 秒 |

### 3.5 追逐阶段要点
- 活动监视器在猎杀期间显示 **10 级**，但 10 级**不总代表**正在猎杀。
- 鬼魂在视线 (LOS) 内或探测到玩家（声音、开启的电子设备）会追击。
- 躲藏点开门状态、玩家是否在门后等会影响探测。
- 部分鬼魂具有专属探测行为。

### 3.6 死亡机制
- 猎杀期间被鬼魂碰到即死亡。
- 死亡会丢失自己购买的装备（初始免费装备不丢）。

## 四、普通猎杀 vs 诅咒猎杀

| 对比项 | 普通猎杀 (Normal Hunt) | 诅咒猎杀 (Cursed Hunt) |
|---|---|---|
| **触发源** | 理智低于阈值后随机 | 仅由**诅咒道具**直接触发 |
| **是否受理智影响** | ✅ 是 | ❌ 否（无视理智阈值） |
| **是否受冷却限制** | ✅ 是（25 秒 / 恶魔 20 秒） | ❌ 否（可紧接普通猎杀发动） |
| **宽限期** | 难度决定（2–5 秒） | **1 秒** |
| **持续时间** | 基础时长 | 比普通猎杀**长 20 秒** |
| **能否被十字架阻止** | ✅ Tier 1 起即可 | **仅 Tier 3 且两次充能完好** |
| **圣木效果** | 可**阻止**开始（90 / 恶魔 60 / 魂魄 180 秒） | 只能**干扰**（致盲/减速/静止），**不能阻止** |
| **可预期性** | 有征兆 | 突然、提示极短 |
| **活动级别** | 显示 10 级 | 显示 10 级 |

> **重要**：诅咒猎杀被取消（因区域无人）不计入冷却计时器。诅咒猎杀之后发动的普通猎杀不算是「真正的」诅咒猎杀，宽限期恢复为难度决定值。

## 五、阻止猎杀的手段

| 手段 | 效果 |
|---|---|
| **十字架 (Crucifix)** | 鬼魂在范围内尝试猎杀时阻止之；鬼魂需等待 25 秒（恶魔 20 秒）再试。Tier 1 挡 1 次，Tier 2/3 挡 2 次。**仅 Tier 3（满充能）可挡诅咒猎杀** |
| **圣木 (Incense)** | 在 3–5 米范围（视等级）点燃后阻止猎杀：**恶魔 60 秒 / 魂魄 180 秒 / 其他 90 秒** |
| **火焰（针对怨灵）** | 点燃的营火/篝火在怨灵 (Onryo) 4 米内可阻止猎杀，但怨灵可吹灭火焰从而无视理智触发猎杀 |
| **猴爪许愿「困住鬼魂」** | 阻止猎杀 1 分钟，但 1 分钟后**强制**触发一次猎杀 |

## 八、逐个鬼魂详细档案

### 【S 级高危】

#### 1. 恶魔 Demon
- **证据**：UV指纹 / 鬼魂笔迹 / 刺骨寒温
- **猎杀阈值**：70%（能力可无视理智任意发动）
- **速度**：1.7 m/s
- **机制**：唯一可在 100% 理智时用能力猎杀；猎杀冷却仅 20 秒（其他 25 秒）；圣木阻止时长短（60 秒）
- **弱点**：十字架对恶魔范围 +50%（Tier 1 即 4.5 米，Tier 3 达 7.5 米）；更易被圣木驱散
- **识别**：理智 >70% 仍猎杀即为强证据；猎杀间隔异常短。早期十字架布设为关键。

#### 2. 拟魂 The Mimic
- **证据**：通灵盒 / UV指纹 / 刺骨寒温（**始终额外显示灵球**）
- **猎杀阈值/速度**：继承当前模仿的鬼魂
- **机制**：每 **30 秒–2 分钟**切换一次模仿对象，行为极不稳定
- **识别**：**灵球作为第 4 条证据出现（即使 0 证据难度也必有灵球）即为拟魂**。行为随模仿对象变化、两次猎杀特性不一致也可确证；但易被误判为所模仿的鬼魂类型（非「与幽灵混淆」）。

#### 3. 雾影 Deogen
- **证据**：通灵盒 / 鬼魂笔迹 / D.O.T.S
- **猎杀阈值**：40%
- **速度**：0.4–3.0 m/s（远距离 3.0，近身 2.5 米内降至 0.4）
- **机制**：**始终知道玩家位置，无法躲藏**；距离越近越慢
- **识别**：站在鬼魂上方时通灵盒传来沉重呼吸声；靠近时急剧减速（可贴近绕柱）
- **应对**：利用其近身极慢的特点贴身周旋

#### 4. 达彦 Dayan（2025 新增）
- **证据**：EMF5 / 灵球 / 通灵盒
- **猎杀阈值**：45% / 50% / 65%（视附近玩家移动状态）
- **速度**：1.2 / 1.7 / 2.25 m/s
- **机制**：**10 米内玩家移动时变强**（速度与阈值提升），**玩家静止时变弱**
- **识别**：猎杀中测试移动/静止；与奥班博 (Obambo) 易混（奥班博按状态时间切换、有固定状态周期，达彦按玩家动作即时响应，且达彦无视野加速）
- **应对**：靠近鬼房时保持静止

#### 5. 加鲁 Gallu（2025 新增）
- **证据**：EMF5 / UV指纹 / 通灵盒
- **猎杀阈值**：40%（疲惫）/ 60%（暴怒）

- **识别**：使用保护道具后反应剧烈；观察暴怒后的减速

# 第八部分：实战策略总结

## 十四、鬼魂识别方法论

### 14.1 三层识别法
1. **证据层**：集齐 3 条证据锁定（噩梦 2 条 / 疯狂 1 条）
2. **行为层**：用鬼魂独特行为剔除选项（速度、灯光、电闸、盐、声音）
3. **猎杀层**：观察猎杀中的速度变化与探测模式

### 14.2 关键「确证」特征（一票定性）
| 现象 | 结论 |
|---|---|
| 出现 **第 4 条假灵球** | 拟魂 Mimic |
| **六指指纹** | 幻妖 Obake |
| **从不踩盐、不留脚印** | 魅影 Wraith |
| **非猎杀时关出口门** | 幽灵 Yurei |
| **冷房加速 + 猎杀可见呼吸白气** | 寒魔 Hantu |
| **抛物线车速从 3.0 降到 1.0** | 亡魂 Revenant |
| **理智 70% 以上就猎杀** | 恶魔 Demon |
| **圣木后 180 秒才敢猎杀** | 魂魄 Spirit |
| **D.O.T.S 只在摄影机中、无人房内显现** | 御灵 Goryo |
| **同房有人则完全不猎杀（35% 阈值）** | 暗影 Shade |
| **瞬移 + 留下 EMF 2/5** | 魅影 Wraith |

## 十五、通用生存原则

1. **电子设备会暴露位置**：猎杀期间关闭手持电子设备。
2. **非电子设备更安全**：鬼魂笔迹书、十字架、圣木、盐、篝火、荧光棒。
3. **十字架只能阻止「开始」猎杀**，猎杀开始后无效。
4. **诅咒猎杀无视理智**，仅 Tier 3 十字架（满充能）可挡。
5. **平均理智仅算存活玩家**，死者不计入——注意团队状态。
6. **鬼魂模型不代表类型**，切勿凭外观判断。
7. **理智值低于 50% / 30% 会出现幻象干扰**（黑影、虚假脚步声），注意分辨。
8. **媒体只算首次独特**，重复捕获奖励锐减。
9. **准备期内无猎杀**（业余 5 分钟 / 中级 2 分钟），可安心布置。
10. **大型地图必须配传感器阵列 + 头戴设备**，长距离情报价值极高。
