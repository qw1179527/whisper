# 《恐鬼症》(Phasmophobia) 场景介绍 —— 初始选择界面与地图场景详解

> 资料整理时间：2026 年 10 月 5 日
> 版本依据：v0.15.1.0（2025 年 12 月冬季更新）及 v0.13 Chronicle
> 译名沿用前几份文档的官方中文译名

# 第一部分：初始选择界面的场景

《恐鬼症》的「初始选择界面」不是单一画面，而是由**主菜单**与其后的**大厅（车库）+ 卡车**两层场景构成。玩家从主菜单进入大厅，再搭乘卡车抵达案发地点。

## 一、主菜单 (Main Menu)

### 1.1 场景性质
- v0.13 Chronicle 更新后，主菜单 UI **完全重做**（保留原有功能）。
- 主菜单为一个**背景化的调查指挥场景**，玩家在此创建/加入房间、选择地图与难度、管理装备与日志。

### 1.2 主菜单功能分区（典型布局）
| 区域 | 功能 |
|---|---|
| **左侧屏幕** | 选择地图 (Map Selection) |
| **中间屏幕** | 角色档案 (Profile)、难度设置、当前卡车配装 (Loadout) |
| **右侧屏幕** | 装备界面（增删卡车库存物品） |
| **商店入口** | 购买与升级装备 |
| **日志入口** | 查看证据、鬼魂、任务、媒体 |
| **设置入口** | 图形、音频、控制、语言 |
| **奖杯陈列柜** | 展示成就与活动奖杯 |

### 1.3 大厅场景 (Lobby / Garage)
- **场景设定**：玩家所处的大厅又称「**车库 (Garage)**」，是调查小队的总部。
- **大厅（车库）为独立可探索场景**（非纯 UI）：
  - 按 **ESC** 退出菜单即进入车库场景
  - 在车库中按 **空格键 (SPACEBAR)** 可返回菜单
- 玩家在此**投票选择地点**，由房主设定难度。
- 玩家可挑选**调查员外观**（角色模型）。
- 装备在电脑处购买与升级，随后装载进卡车。

### 1.4 房间创建与筛选
- **游玩风格 (Playstyle)**：休闲 (Casual) / 硬核 (Hardcore) / 角色扮演 (Roleplay)
- **硬件偏好**：需要 VR / 需要麦克风
- **房间浏览器**：可按难度、硬件、游玩风格筛选；显示难度（或自定义倍数）与所选地图
- 支持自定义难度重命名、Twitch Drops

# 第二部分：卡车（调查车）场景

卡车是玩家**真正的初始出生点**，也是全程的后勤与指挥中心。

## 二、卡车内部布局

### 2.1 左侧：任务板 (Objective Board)
- **白色任务板**，包含：
  - **四个可选任务**（所有玩家共享）
  - **鬼魂信息**：鬼的名字、其回应**多人**还是**单人**
- 每完成一个任务获得金钱奖励，奖励随难度翻倍。
- **注意**：在房内叫鬼的名字会激怒它；也可尝试命令它关灯、开门等。

### 2.2 右侧：屏幕组（四屏布局）
| 位置 | 屏幕 | 功能 |
|---|---|---|
| **左上** | **建筑地图 (Map)** | 显示建筑布局，可用白色按键切换楼层；一楼外围**绿色横线**为出入口，**绿色电池图标**为电闸位置；黄点为地图自带摄影机；布置好的运动传感器以黄线显示（触发时变绿） |
| **右上** | **声音传感器屏 (Sound Sensor Screen)** | 安装了声音传感器后显示该区域音量大小 |
| **左下** | **玩家理智值 (Sanity Monitor)** | 显示团队平均理智与个人理智；平均越低越频繁猎杀；个人越低越易见灵异现象；可吃理智药恢复。（部分难度下该屏可能被禁用以碎裂屏幕呈现） |
| **右下** | **活动强度 (Site Activity Monitor)** | 显示鬼魂活跃度（1–10 级）；**10 级代表可能正在猎杀**；不能作为 EMF 5 级证据。（部分难度下可能被禁用） |

### 2.3 右侧：装备架 (Equipment Shelves)
- 玩家带入的所有装备摆放在**右侧铁置物架**上。
- **每人最多携带 3 件**，可随时返回卡车更换。
- 典型摆放：左上 EMF 读取仪；中排通灵盒 / 鬼魂笔迹书 / D.O.T.S；右上摄影机；下方温度计 / 紫外灯 / 闪灯。

### 2.4 监控电脑 (CCTV Computer)
- 查看地图自带摄像头与玩家摆放的摄影机画面。
- **键盘切换夜视模式，鼠标切换不同镜头**。
- 显示器上方计时器为**准备时间倒计时**。

### 2.5 准备时间计时器
| 难度 | 准备时间 |
|---|---|
| 业余 | 5 分钟 |
| 中级 | 2 分钟 |
| 专家及以上 | 0:00（开局即怒） |

> 计时**从打开建筑大门时开始**。准备期内无猎杀，可安心搬运与布置；时间不够时可先把装备搬至大门前再开门。

### 2.6 出发流程
1. 携带钥匙（键盘旁）→ 点击卡车门旁的数字键盘锁
2. 走到建筑前门 → 开门（即激活鬼魂、开始计时）
3. 展开调查

### 2.7 卡车附近的附属场景
- **车库 (Garage)**：大厅/装备管理场景（见第一部分）。
- **卡车停放区**：卡车停在案发地点（房屋、营地等）外的场地，是玩家与建筑之间的过渡空间。

# 第三部分：地图内各场景介绍

## 三、场景分类与总体机制

### 3.1 尺寸分类
地图按规模分为**小 / 中 / 大**三类，尺寸决定**可能鬼房数量、藏身点数量、理智管理难度**。

| 规模 | 特点 |
|---|---|
| **小型** | 房间少、结构紧凑、可快速完成调查；走廊狭窄、视野受限 |
| **中型** | 多层、房间多、需更多协调与声音传感器等设备 |
| **大型** | 广阔内部、长走廊、多楼层、藏身点极多、后勤压力最大 |

### 3.2 环境机制
- **动态天气系统**：从晴天到暴雪、雷暴。雨风可掩盖脚步声与 EMF 提示音；室外低温会干扰刺骨寒温判定。
- **声学差异**：机构类地图（精神病院）有回声；营地类有户外天气影响声音传播。
- **锁定机制**：大图在猎杀时**所在分翼/分支会封锁**，更难躲藏。
- **诅咒道具固定出生点**：每张地图有固定刷新点，每次合同仅出现一件（自定义难度可能更多）。

## 四、小型住宅地图

### 4.1 6 Tanglewood Drive（坦格伍德街 6 号）
- **解锁**：开局即可用
- **结构**：单层三卧两卫的郊区别墅 + 恐怖地下室
- **特点**：游戏**最具标志性的入门地图**，也是**教程地图**，常用于速通
- **风险**：藏身区域少，猎杀时较危险
- **常见鬼房**：主卧、儿童房、地下室、厨房
- **重做**：v0.16 更新重制，提升道具摆放与视觉保真度

### 4.2 42 Edgefield Road（埃奇菲尔德路 42 号）
- **解锁**：等级 2
- **结构**：两层、六卧、带地下室的红砖住宅
- **特点**：房间多，猎杀时**容易找到藏身点**
- **场景**：楼上若干卧室与卫浴，一楼亦有一卧一卫

### 4.3 10 Ridgeview Court（岭景苑 10 号）
- **解锁**：等级 2
- **结构**：两层四卧，带地下室与车库
- **特点**：空间较大，猎杀时**容易找到藏身处**
- **重做**：2026 年更新加入**动态光照与改进的声音遮蔽**，提升氛围

### 4.4 13 Willow Street（柳树街 13 号）
- **解锁**：等级 9
- **结构**：单层两卧一卫小屋
- **特点**：**无储物柜/衣橱**，玩家只能利用家具与墙角蹲藏，**猎杀时极危险**（易被逼入死角）
- **重做**：2026 年重制资产质量，保留「无衣柜」的核心难度

### 4.5 Camp Woodwind（伍德温营地）
- **解锁**：等级 19
- **结构**：小型、**开阔的户外营地**
- **特点**：缺乏传统墙壁，猎杀时**很难躲避**；需更依赖营火与圣木
- **场景**：帐篷、林间空地等
- **诅咒道具**：闹鬼镜子靠在营地中央大树旁

---

## 五、农舍地图

### 5.1 Grafton Farmhouse（格拉夫顿农舍）
- **解锁**：等级 4
- **结构**：两层农舍，**无阁楼**（两栋农舍中较小者）
- **特点**：房间宽敞，**压迫感较低**；**吱呀作响的地板**会暴露鬼魂位置
- **常见鬼房**：工坊 (Workshop)，以**高密度可互动物件**著称
- **重做**：v0.14（2025.8）重做，新增**新阁楼、全新布局、重设主题房间**
- **诅咒道具**：召唤阵藏在楼上**满是诡异娃娃的房间**（远窗附近）

### 5.2 Bleasdale Farmhouse（布雷斯代尔农舍）
- **解锁**：等级 4
- **结构**：两层木结构农舍 + **三层阁楼**（两栋农舍中较大者）
- **特点**：**氛围感极强**的阁楼与木质结构**放大环境噪音**；藏身点多（储物柜、家具、置物架）
- **风险**：**阁楼几乎不可能藏身**，且难以摆脱鬼魂追击
- **重做**：2025 年完全重制，**视觉增强 + 布局重做 + 新增户外花园**（含鬼房）
- **诅咒道具**：塔罗牌放在阁楼卧室的**水晶球**旁

## 六、中型公共建筑

### 6.1 Prison（监狱）
- **解锁**：等级 15
- **结构**：共 **31 个房间，其中 29 个可能为鬼房**
- **场景**：中央放风场、食堂、**两个牢房区（Cell Block A/B）**；鬼魂可在多层回廊间自由游走
- **特点**：**大部分区域完全开阔，藏身点少**；可从安保摄像头**不出卡车就看到灵球**
- **风险**：牢房区 A 为危险开阔区
- **诅咒道具**：全部七件刷新在**入口走廊尽头、双开门之前**

### 6.2 Maple Lodge Campsite（枫叶旅馆营地）
- **解锁**：等级 19
- **结构**：**完全户外**的营地
- **场景**：野餐区、帐篷、木屋、**湖边**；物件密集散布
- **特点**：**天气效果（雨、雾）严重影响能见度**；收集部分证据类型较困难
- **诅咒道具**：召唤阵在码头旁木屋（**需蓝钥匙**开启）；闹鬼镜子在接待楼沙发上

### 6.3 Point Hope（希望角灯塔）
- **结构**：**垂直玩法**——需攀爬数层楼梯抵达**灯室 (Lantern Room)**
- **特点**：**七层楼层，每层各放一件诅咒道具**，需完整搜索整栋建筑；诅咒猎杀时形成独特瓶颈
- **场景**：海岸灯塔，**海岸风效增加音效层次**

### 6.4 Sunny Meadows Restricted（晴草甸精神病院·限制区）
- **解锁**：等级 22
- **结构**：从晴草甸精神病院中**随机选取一个独立分翼**
- **特点**：中型规模中带机构氛围，猎杀时封锁所在分支

## 七、大型机构地图

### 7.1 Brownstone High School（布朗斯通高中）
- **解锁**：等级 11（原为中型地图，后归为大型）
- **结构**：两层、数十间教室、**体育馆**、图书馆、储物柜
- **特点**：**完全黑暗**、氛围压抑；氛围营造令人不适
- **风险**：**体育馆是最差鬼房**，其次为走廊；大堂可为鬼房，但**走廊不能为鬼房**
- **识别方式**：常需通过开门声或电话铃声追踪鬼魂
- **诅咒道具**：全部七件刷新在**大堂**（两根立柱之后）

### 7.2 Sunny Meadows Mental Institution（晴草甸精神病院）
- **解锁**：等级 22
- **结构**：规模庞大，分为多个**独立分翼**——**限制病房 (Restricted Ward)、礼拜堂 (Chapel)、庭院 (Courtyard)** 等
- **特点**：**替代了原来的疯人院 (Asylum)**；面积庞大、耗时最长
- **风险**：猎杀时**所在分翼封锁**，极难躲藏；房间高度相似，**极易迷路**
- **诅咒道具**：全部集中在**礼拜堂**（大十字架下方的巨型地面符号周围）
