## 与本工程已发现问题的对应关系（**读这批资料最该先看这几条**）

### ① 「疗养院地图重做了吗」—— 官方重做了，而本工程还是旧的那张
`04-场景介绍…` §7.2：
> **Sunny Meadows Mental Institution（晴草甸精神病院）替代了原来的疯人院 (Asylum)**

本工程持有的是 `asylum_v1.json` —— **即被替代掉的旧图**。
官方新图的结构是**多个独立分翼**（限制病房 / 礼拜堂 / 庭院），
且**「房间高度相似，极易迷路」是刻意设计**，不是缺陷。

### ② 「谁家医院这样」（纯色一片）—— 参考资料给了材质方向
医院观感靠**不同色相拼**：浅绿墙裙 / 灰地砖 / 白吊顶 / 深金属门框。
而本工程此前是 **一个基色乘不同亮度**（`Scale(ZoneBase(zone), k)`），
必然呈现"纯绿一片"。已按此重做 `LevelPalette`（见该文件注释）。
