**道具分类（按用户定义）**：
- **放置性道具**：可放在地上，行为由放置位置决定（盐、运动传感仪、鬼魂笔记、点阵投影仪）
- **一次性道具**：用掉即消失（盐、圣木）
- **可丢可捡道具**：可丢在地上、可再拿起，**其他玩家也能拿**（烛台、理智药、通灵盒、EMF、相机…）
- **头戴式道具**：**不可丢弃**，只能放回车里（头戴摄像头 / 夜视仪等）
- **携带上限**：**一个玩家同时最多 3 件道具 + 1 件头戴式工具**

## 一、道具设定（用户原文 + 我补的 EMF）

### 1. 盐（放置性 · 一次性）

| 项 | 内容 |
|---|---|
| 分级 | **一级 = 罐装盐（1 次）**；**二级 = 袋装盐（2 次）** |
| 使用 | 点击「查看键」→ 撒在地上 → **撒完道具消失** |
| 机制 | 鬼经过盐上会**留下痕迹** |
| 建模 | ⚠️ **耐久不同时，手上的建模不同**（罐装 vs 袋装） |
| 动画 | 需要"撒盐"动作 + 盐落地成形 |
| 已知交互 | 魅影(Wraith) **永远不会踩到盐堆** → 盐不是通用的 |

`【待核实】` 盐堆痕迹的**可见性规则**（谁能看见痕迹？是否需要紫外线照射才显形？痕迹持续时间？）以及**盐堆是否阻挡/减速**普通鬼。

---

### 2. 圣木（一次性 · 可丢出）

| 项 | 内容 |
|---|---|
| 使用 | 点击「查看键」→ **点燃** → **3 秒内燃烧消失** |
| 动画 | **燃烧动画 + 逐渐消失动画** |
| 生效时机 | **点燃的一瞬间就生效**（不等烧完） |
| 可丢出 | **未点燃的圣木 与 已点燃的圣木 都可丢出** |
| 猎杀中效果 | 在鬼周围点燃 → **普通鬼丢失目标并定在原地 5 秒**，5 秒后恢复正常 |
| 非猎杀时效果 | 在鬼周围点燃 → **重置鬼的猎杀时刻**，使普通鬼 **90 秒内无法发动猎杀** |
| 例外 | **魂魄(Spirit)：150 秒**内无法猎杀（普通为 90s）· **恶魔(Demon)：仅 60 秒** · **魔洛伊(Moroi)：致盲时间更长（7.5 秒）** |

`【待核实】` "在鬼周围"的**判定半径**（几米内算"周围"？）· 是否需要**对准鬼**还是**任意方向**均生效 · 圣木对**诅咒猎杀**是否无效（用户第 4 条说诅咒猎杀"无法用圣木阻止"）。

---

### 3. 烛台（可丢可捡）

| 项 | 内容 |
|---|---|
| 使用 | 点击「查看键」→ **点燃** |
| 携带 | 点燃后**可拿在手里**，**也可放置在地上** |
| 鬼的互动 | 鬼有**一定概率吹灭蜡烛**，引起互动 |
| 复燃 | **被吹灭的蜡烛可再次点燃** |
| 火焰的作用 | 幽灵(Yurei) **在火焰覆盖区域内不会开启猎杀** · 怨灵(Onryo) **火焰可阻止其猎杀** |

`【待核实】` 蜡烛**照亮范围**（米）· **吹灭概率**（每次判定间隔？）· 蜡烛是否**消耗**（烧完消失还是永久）· 是否提供理智恢复。

---

### 4. 运动传感仪（放置性）

| 项 | 内容 |
|---|---|
| 使用 | 放置在地上，形成一条**判定线** |
| 判定线显示 | 以**红外线方式在玩家视角里显示** |
| 物理规则 | 红外线**符合真实物理引擎**：**碰到墙体不再延伸**，**碰到镜子会反弹** |
| 判定范围 | **只为其判定线的范围**；判定线**长度有限**、**只为直线**、**不会穿墙**、**不会折射** |
| 触发 | 鬼经过其判定线时**发出响声** |

⚠️ **这里用户描述内部有张力，需澄清**（见第九节 Q3）：
"碰到镜子会反弹" 与 "只为直线、不会折射" 字面上冲突。我的理解是：
**红外线本身会因镜子反射而改变方向（这是"显示"层面的物理）**，
但**传感器的有效判定仍只是那条初始直线段**（反射后的线只是视觉，不算判定）。
**这个理解需要用户确认**。

`【待核实】` 判定线的**长度**（米）· 响声的**可闻范围**（是否只有放置者听到？是否作为刺激源引鬼？）· 触发后**是否消耗**。

### 5. 理智回复药（可丢可捡）

| 分级 | 效果 | 动画 |
|---|---|---|
| **一级：理智药** | 回复 **15 点**理智 | **有使用动画**，且**其他玩家可见** |
| **二级：肾上腺素** | 回复 **30 点**理智 | 同上 |

`【待核实】` 使用**耗时**（几秒？期间能否移动？）· 是否有**冷却** · 是否**一次性消耗**（用户把它归在"可丢可捡"，所以应是消耗品但可传递）。

---

### 6. 通灵盒（Spirit Box，可丢可捡）

| 项 | 内容 |
|---|---|
| 使用流程 | 手握 → 点击「查看键」→ **液晶屏幕提示"开始使用"** → 麦克风检测到音量时**启动判定** |
| 判定频率 | **每 0.5 秒刷新一次状态** |
| 回应概率 | 玩家在鬼怪附近**且该鬼怪"有此证据"** → **5% 概率**收到鬼的回复 |
| 音频 | **仅使用玩家能听到**鬼的回复音频 |
| 关闭 | 再次点击「查看键」→ 提示**关闭使用** |
| 建模 | **参考恐鬼症原版建模** |

`【待核实】` **提问机制**：恐鬼症原版需要**先问问题**（"Are you here?" 等）鬼才会回应；
用户描述的是"检测到音量即判定"，**没有提提问环节** → 需确认是**简化版**（有声音就判定）还是**完整版**（必须提问且用特定句式）。
另需核实：**"鬼怪附近"的半径** · 回复音频的**语种/内容** · 是否**消耗**（恐鬼症中通灵盒是设备、不消耗，只耗电/需开开关）。

---

### 7. 鬼魂笔记（Ghost Writing Book，放置性）

| 项 | 内容 |
|---|---|
| 使用 | 放置在地面 |
| 触发 | **有此证据的鬼**经过时 → **8% 概率写下笔记** |
| 建模 | **写下的笔记 与 未写下的笔记 建模不同** |
| 表现 | 鬼写笔记时有：**写笔记的声音** + **写笔记的动作** |
| 声音范围 | **只有在一定范围内的玩家能听见** |
| 关键细节 | **写笔记时笔是悬空写的**（鬼不可见，笔自行书写） |

`【待核实】` **判定半径**（鬼离书多近算"经过"？）· **声音的可闻范围**（米）· 是否**每次经过都判定**（还是每局只判定有限次）· 书是否**消耗**。

---

### 8. EMF（用户补充设定）

| 等级 | 触发 |
|---|---|
| **1~4 级** | 鬼在**一定范围内互动**时响起 |
| **5 级** | **有 EMF 5 级证据的鬼**在互动时 **8% 概率**响起 |
| 猎杀时 | **普通鬼**在猎杀时 EMF 警报会在 **1~5 级间随机**响起 → **此时 EMF 判定不准** |

`【待核实】` EMF **1~4 级的判定规则**（是随机 1~4 还是按互动强度映射？）· **"一定范围"的半径** ·
EMF 是否**持续显示峰值**（恐鬼症中 EMF 读数会短暂停留）· 是否需要**玩家手持 EMF 且靠近**才算。

## 三、鬼怪通用行为（用户原文）

1. **猎杀时**：在其**一定范围内**的玩家会**触发心跳声**（**自己只能听见自己的**）
2. **猎杀时**：有**脚步声**（**与速度成正比，速度越快脚步声越快**）与**闪烁**
3. **猎杀时**：可**抛掷互动物品**
4. **诅咒道具**：每张地图**随机刷新其中一种**（见第四节）
5. **猎杀节奏**（**重点**，见第五节）

`【待核实】` 心跳声的**触发半径** · 闪烁的**频率与模式**（是否与鬼的类型相关）· 抛掷的**力度/伤害**。

## 五、猎杀节奏机制（用户第 5 条 —— **明确要求"这个机制要做好"**）

用户原文要点，逐条拆解为可实现规则：

| # | 规则 | 实现含义 |
|---|---|---|
| 1 | **并非理智阈值一到就疯狂猎杀** | 理智只是**触发条件之一**，不是"到了就必猎" |
| 2 | **理智越低猎杀越频繁，但绝不是一直猎杀** | 猎杀频率 = f(理智)，且 **f 有上限**，不能退化成"连续猎杀" |
| 3 | **鬼在猎杀时不能再次猎杀** | 猎杀中有**互斥锁** |
| 4 | **不能刚猎杀完再猎杀** | 猎杀结束 → **冷却计时器**启动 |
| 5 | **一般至少间隔 60 秒** | **默认冷却 = 60s** |
| 6 | **恶魔可最低缩短至 20 秒，但绝不是完全依照这个时间猎杀** | 恶魔冷却 **20s**，但**不等于每 20s 必猎** |
| 7 | **有时候可以一直不猎杀** | 允许**长时间不猎杀**（随机性/条件未满足） |
| 8 | **可以间隔 120s 猎一次，然后依据机制与理智忽然 60s 猎一次** | 间隔**可变**，依条件动态变化 |
| 9 | **恶魔有时也能一直不猎** | 即使是恶魔也**不保证**最短间隔必猎 |

**`【建议】` 可实现的模型（供讨论）**：
```
每次冷却结束时：
  P(猎杀) = 基础概率 × 理智系数 × 鬼种系数 × 条件系数
  若 P 抽样失败 → 重新等待一个较短间隔（如 10~20s）再判定一次
  → 这样自然产生"有时 60s、有时 120s、有时一直不猎"的分布
```
**关键**：不能用"冷却到点必猎"的硬实现，否则会退化成"定时猎杀"，违背用户第 1、2、7、9 条。

`【待核实】` 恐鬼症原版的**猎杀触发**是"**理智低于阈值后，每次互动/事件累积概率**"的机制。
需核对：**概率基数**、**累积方式**、**是否与互动次数相关**、**难度设置的影响**。
用户第 9 条说"恶魔有时也能一直不猎" → 说明是**概率型**而非**定时型** ✅ 与我的建议模型一致。
