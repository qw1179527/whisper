# 医院平面规划（三层）· 待批

> **为什么重做**：用户原话「出生点左边就有一个门，进去后就一个小房间在连接病房区，哪个医院会这么设计」
> 「走廊到头后的房间不知道是什么」。当前 `asylum_v1` 是按"几何不重叠"凑出来的连通图，
> **没有医院动线**：入口 4×3 的小屋直接怼在病房走廊端头，走廊尽头没有功能落点。
>
> **本文件是施工前的蓝图**。确认后才改 `tools/gen-asylum-v1.mjs` 与套件配方。

## 一、设计原则（真实医院动线）

1. **入口要有前厅**：进门 = 接待/分诊/等候，不会一进门就撞到病房走廊。
2. **走廊要有层级**：主通道（宽 3.6~4.2m，能过担架对向）→ 支廊（2.4~3.0m）→ 病房前室。
3. **走廊尽头必须有落点**：楼梯间 / 电梯厅 / 处置室 / 污物间 / 太平间门，**不能是"不知道是什么的房间"**。
4. **洁污分流**：病房区与污物/太平间不能共用一个前室。
5. **病房成组**：护士站居中，病房分列两侧（真实病房楼的标准做法）。

## 五、跨层竖井（当前 DSL 的缺口）

DSL 目前**不支持跨层走廊**（`gen-asylum-v1.mjs` 的 `_note` 已自认此事）。需要新增：
```jsonc
"shafts": [
  { "id": "stair_A", "kind": "stair", "rooms": ["ground/stairwell","floor1/stairwell","base/stairwell"], "travelSeconds": 6 },
  { "id": "lift_A",  "kind": "elevator", "rooms": ["ground/elevator","floor1/elevator"], "travelSeconds": 4, "needsPower": true }
]
```
产品侧要新增：`LevelLoader` 解析 `shafts`、`GameBootstrap` 用**触发器**（玩家进入竖井范围 → 换层位置 + 过渡）。
**注意**：换层要重置 `LevelGeometry` 的碰撞上下文（每层一套网格），这是这个特性的主要复杂度。

## 六、套件配方要扩的种类

现有配方：`hall` / `ward` / `morgue` / `bed` / `cabinet`。
新增：`lobby`（接待台/座椅/导视）· `nurse`（环形台/病历架）· `office`（桌/柜/白板）·
`pharmacy`（药架/保险柜）· `utility`（污衣车/水槽）· `storage`（货架）· `stair`（楼梯/扶手/防火门）·
`lift`（电梯门/按钮板）· `boiler`（管道/配电柜）· `cold`（冷藏架）。
**每个都要按房型尺寸出**（生成器已参数化，扩配方即可）。

## 七、门交互（与地图同步做）

按地点分类型（这是"不同地方的门要符合情景"）：

| 类型 | 用在 | 行为 |
|---|---|---|
| 病房平开门 | `ward_*` | 推入式、带观察窗、开合有铰链音 |
| 走廊双开门 | `corridor_*` 端头 | 双向推开 |
| 太平间推拉门 | `morgue_*` | 横向滑轨、无声 |
| 禁区磁卡门 | `pharmacy`/`cold_room`/`utility` | **上锁**，需钥匙卡；开时有电子音 |
| 楼梯间防火门 | `stairwell` | 常闭自闭、推杆式 |
| 电梯门 | `elevator` | 需要供电（停电事件时失效） |

产品侧：`DoorController`（状态 closed/opening/open/locked + `LevelGeometry` 同步开关）+
`DoorDefinition` DSL 字段（`type`/`locked`/`key`）+ 门的**碰撞体**（现在门只是墙上的洞，能直接穿过去）。

## 八、本次一并要修的既有缺陷

| 缺陷 | 现状 | 修法 |
|---|---|---|
| **贴墙穿模** | 相机贴墙能看到墙背面 | 取证确认是"近裁剪面 + `Cull Back`"还是别的；再决定改近裁剪/双面/加内衬 |
| **套件无碰撞** | 冷柜/病床/暖气片能穿过去 | "阻挡类"套件部件并进 `LevelGeometry` |
| **光渲染** | 只吃一盏方向光 | 扩 ForwardAdd pass（手电筒/室内点光） |
| **角色建模** | 无角色模型 | 按眼高 1.7m 标定比例；第一人称只影响联机可见性 |
| **物品大小标定** | 未按视角校准 | 门 2.0m / 床 0.9×2.0 / 柜 0.8×0.5 已有；其余按真实医院尺寸表对齐 |

## 九、执行顺序（建议）

1. **跨层竖井 DSL + 产品支持**（三层的前提，且是最大技术风险 → 先验证）
2. **配方扩展**（10 种新套件，生成器已参数化）
3. **三层布局表 + 生成 + 自检**（生成器会拦共享墙/开口对齐/重叠）
4. **门交互 + 门碰撞**（与布局同步，因为门位在布局里）
5. **套件碰撞 + 贴墙穿模 + ForwardAdd**（渲染与物理）
6. **角色建模 + 尺寸标定**
7. **真机逐层取证**（每层走到落点、每类门开合、贴墙 A/B 像素判据）
