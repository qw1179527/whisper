## 二、**理智系统**（`/gameplay/sanity`）—— 带精确数值

### 起始与判定口径
- 起始 **100%**（**Nightmare 75%**，自定义按设置）；
- **个人理智**：粗略看手表、精确看**货车内监视器**（**Nightmare/Insanity 下监视器可能说谎**）；
- **平均理智** = 存活玩家的平均 —— **几乎所有猎杀与活动判定都用它**；
  队友在外面 0 理智时，你在屋里高理智也照样遇到"凶"鬼；
- **Banshee 猎杀只看其目标**的理智；
- **死者不计入平均**，其理智几乎不动（除"队友死亡"罚与部分能力/道具）；
- **0% 不触发任何特殊事件**（除每日任务），理智**不会低于 0**；
- **理智在第一次打开出口门之后才开始下降**；**在建筑外不产生被动流失**。

### 被动流失（黑暗）—— 按地图大小 × 难度
| 地图 | Setup 阶段 | 正常阶段 |
|---|---|---|
| 小 | 0.09 %/s | 0.12 %/s |
| 中 | 0.05 %/s | 0.08 %/s |
| 大 | 0.03 %/s | 0.05 %/s |

**难度乘数**：Amateur ×1 · Intermediate ×1.5 · Professional/Nightmare/Insanity ×2；
**Blood Moon 再 ×2**（原文：给流失乘数再加 ×1）；**单人被动流失减半**。
**Setup 阶段理智不会因任何来源低于 50%**（但**挡不住鬼能力与诅咒道具**）。

**关键细节（容易做错）**：
- 流失取决于房间的**主光源（天花板灯、墙上开关）**是否开启 → **主灯全开时该房间被动流失 = 0**；
- **台灯 / 落地灯 / 电视 / 监视器 / 手电 / 设置里的亮度 都不能停止流失**；
- 大型暗区（如 Sunny Meadows 走廊）**即使开了主灯也只降到 80%**，不会归零；
- **火源（firelight）在 2 m 内按等级降低（I 约 33%、II 50%、III 66%）但不归零**。

### 各来源扣减（精确值）
| 来源 | 数值 |
|---|---|
| 队友死亡 | **−15%**（所有人，含已死者） |
| 撞上多数事件鬼影 / "云团" | **−10%**（Banshee 对目标 −15%；Oni −20%） |
| **Jinn** 能力（附近且电闸开启） | **−25%** |
| **Yurei** 能力（附近关门） | **−15%** |
| **Moroi** 诅咒（Spirit Box/抛物面/录音） | **被动流失翻倍**，且**光与火源都压不住** |
| **Phantom**（现身时心跳区内） | 约 **0.5 %/s** |
| **Poltergeist** 投掷爆炸 | **−2% × 物品数** |
| 镇静剂 | **恢复**（比例随难度/等级） |
| 塔罗 太阳/月亮/命运之轮 | **→100% / →0% / ±25%** |

## 三、**常见误区**（`/gameplay/common-misconceptions`）—— 用于**纠错**，防止把错的写进配置

| 误区 | 官方事实 |
|---|---|
| "待在亮房间总能防止理智流失" | 只有**主灯**能完全停止；大暗区只降到 80%；火源只降低 |
| "开局无线电播报暗示鬼的类型/行为" | **纯氛围**，随机选取，与鬼无关 |
| "拍照自己的尸体能拿保险" | 无关；保险**自动**发放，覆盖你加入合约的装备成本（仅 Amateur/Intermediate 及自定义中含保险者） |
| "EMF 读数高 = 更危险" | **无关**；EMF 各等级对应具体行为（**关门=2 级、扔物=3 级**），**读数不累加**（两扇门各 2 级 ≠ 4 级） |
| "EMF 5 = 即将被攻击" | **EMF 5 只是随机事件**，可发生在 2/3 级信号时，与攻击无关 |
| "房间里最低温处 = 鬼的确切位置" | 鬼在房内时**整间房**降温；温度本就波动 |
| "问 Ouija『你最喜欢的房间』= 最喜欢的房间" | 回答**始终是当前房间**；只有**闹鬼魔镜**显示"最喜欢的房间" |
| "蜡烛熄灭的烟说明鬼互动过" | 烟**始终相同**；但**被鬼吹灭**会有特有的"呼气"声 |
| "用 Spirit Box 会掉理智" | 用与得到回答**本身不掉**；掉的是因需在黑暗中（被动流失）；**Moroi 有特殊诅咒**会加速 |
| "叫鬼的名字会引发猎杀" | **只会提高互动概率，不引发猎杀**；唯一例外 **Yokai**（附近说话会**提高猎杀阈值**，但不是"喊了就猎"） |
| "有 EMF5 证据的鬼在猎杀时会给 5 级" | 猎杀/事件期间电子干扰只给 **1–4 级**；猎杀时测 EMF5 **无用且危险**（开启的 EMF 会暴露你） |
| "只要有一个玩家理智高就不会被猎" | **按平均**（在场内外都算）；例外 **Banshee 只看目标** |
| "鬼会追到建筑外或货车里" | **不是机制**（遇到多为改档/外挂）；曾有**外门 hitbox bug** 可隔门杀人，非设计 |
| "鬼能透视门与墙" | 多数（含 Spirit）**不能**；但**猎杀时所有鬼都能穿过门**；唯一透视的 **Deogen**（始终知道你在哪，躲藏无效） |
| "鬼记得上次你躲哪" | 只在**上次真的发现过你**（视线/电子/声音）时才"记得" |
| "关了全部灯鬼就看不到我" | 鬼的视觉**与黑暗无关**；但鬼不"看见"手电的光，而是把它当作**活动电子设备** |
| "用全局语音会害死别人" | 只在**按键者靠近鬼**时吸引它 |
| "篝火影响 Hantu 速度" | 不影响；**只有房间温度**影响 Hantu 速度（现仅 Camp Woodwind 篝火与 Sunny Meadows 锅炉房会改室温） |
| "Jinn 不能与电闸门互动" | 所有鬼（含 Jinn）**都能**开电闸门；Jinn 只是**不能按里面的开关切电** |
| "Jinn 更爱碰电子设备" | 无此加成 |
| "Obake 能变形成玩家模型" | **不能**；只是猎杀闪烁时短暂变成**同性别另一种鬼模型** |
| "Onryo 躲火" | 火**不影响** Onryo 移动；明火只是像十字架一样**阻止猎杀开始** |
| "Onryo 熄火后的猎杀无视十字架" | 仍可被十字架/圣木/明火阻止（唯一不可阻挡的是**诅咒猎杀**，除非附近有完好三级十字架） |
| "Raiju 从任何电源取能" | 只从**从货车带出的活动电子设备**（开启的手电/传感器/投影仪/头戴摄像机）；**建筑供电设备（灯、收音机、电脑、电视）不算** |
| "Mimic 的鬼火行为不同" | 相同（留在最爱房间、随机移动、随最爱房间变化而换房） |
| "Twins 是两个鬼" | 代码里是**一个鬼**，但有**两个互动区**（普通 + 很远也能互动的"扩展区"）；猎杀开始有 **50/50** 概率从当前位或近期扩展互动区发起 |
| "鬼会不惜一切避开盐" | **不会**；鬼只是直接走过盐（含猎杀时），无其他互动 |

## 四、货车屏幕规格（`/van/*`）

### ① 地点地图（`/van/site-map`）
位置：**货车内左上角**。显示：地图名称 + **房间平面图** · **玩家位置**（颜色与理智监视器一致）+ **朝向指示器** ·
**出口（绿线）** · **楼层楼梯（带箭头图标）** · **监控摄像头**（正在投放到监视器的标**绿**、其余**黄**）·
**电闸位置**（随难度可能变） · 老地图红线标**窗户** ·
**玩家放置设备**：运动传感器 = 红线（触发变绿 + 声音）；声音传感器 = 半透明橙色半径区（老版黄色）。
显示样式：**0.4.0 之后重做的地图用俯视图**（含外部区域/物体/光照/贴图）；老地图为简化灰线轮廓。
**楼层切换在地图左侧的上下箭头**，左键切换，**箭头不循环**。

### ② 声音传感器监控器（`/van/sound-monitor`）
位置：**活动监视器上方**。规格：
- 显示**最多 4 个声音传感器**，形式为**水平条形图**；
- 放置时按**所在区域**在监视器上标注；
- 捕获的声音以**黄色条 + 百分比**（按检测到的音量）显示，并把**实时声音**传回货车；
- **可借此在不进建筑的情况下发现 EMF 5 与"笔记本笔迹"证据**；
- 早期可用来**定位鬼房**。

## 六、立即能用于本项目的三条
1. **理智流失公式可完全照抄**（地图大小 × 难度乘数 + Setup 保底 50% + 单人减半 + 血月 ×2）——
   这些数值应写进 `data/config.json` 并标 `_src: official`；
2. **"主灯才能停流失"**这条会直接影响 `SanitySystem.Tick` 的调用口径（我们目前按 `TorchOn/LightsOut` 两个布尔，
   应改为"该房间主灯是否开启 + 是否处于大暗区 + 附近是否有火源及其等级"）；
3. **误区清单里有 5 条是本项目已写错或可能写错的**（EMF 不累加、EMF5 与猎杀无关、最低温≠鬼位置、
   Ouija 回答的是当前房间、叫名字不引发猎杀）—— 应在机制细化那一轮**逐条对照修正**，避免把错的当官方。
