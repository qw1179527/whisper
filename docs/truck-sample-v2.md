## 一、v1 → v2 的修复（对照渲染图逐条可核）

| # | v1 缺陷（渲染图暴露） | v2 修法 | 验证 |
|---|---|---|---|
| **D1** | 驾驶室与厢体**错位**：挡风玻璃放在 `y = CAB_CY + CAB_L*0.5 - 0.05`（**方向反了**，越出前脸）；驾驶室高 2.2 未与厢顶对齐 → 视觉"矮一截、前脸悬空" | ① 驾驶室顶**对齐厢顶**：`CAB_H = BOX_TOP - CAB_BOT = 3.29 - 0.60 = 2.69`，中心 z = 1.925；② 挡风玻璃贴**前脸内侧** `y = CAB_Y0 + CAB_L - 0.03 = 7.47` | 渲染图里驾驶室与厢体顶面**连成一条线** |
| **D2** | 车轮**像贴在车身外侧**：轮心 `WX = 1.04`，无轮拱/挡泥板 | 轮心内移到 **0.94**（外沿 1.09 < 厢半宽 1.2）；新增 **4 件挡泥板**（`fender_F/R_L/R`，x = ±1.19）罩住上半轮 | 渲染图里车轮**落在车身投影内**、上缘被挡泥板遮住 |
| **D3** | 坡道**脱体**：平放地面，看不出是车尾坡道 | 顶端正中挂车尾板下沿 `(0, 0, 0.95)`，绕 X 轴下倾 **18°**；中心 = 顶 − 半长·方向 | **数值闭合**：顶边 = (−0.760845 + 0.8·cos18°, 0.702786 + 0.8·sin18°) = **(−0.000, 0.950)** ✓ |
| 观感 | "两个白盒子"，没有商用车轮廓 | 新增 **12 道侧板竖筋**（6/侧）· 后视镜（臂+镜）· 车顶导流罩 · 驾驶室踏步 · 底盘大梁 · 左右侧裙 | 渲染图里一眼能认出是厢式货车 |

**规模**：v1 = 39 零件/3188 三角面 → v2 = **64 零件/3104 三角面**（零件翻倍、面数几乎不涨 —— 说明"细节"不必靠面数堆）。

## 二、坐标体系（v1 的教训：**先算再建**）

```
车厢底板 FLOOR_H = 0.95；厢顶 BOX_TOP = 0.95 + 2.3 = 3.29
驾驶室：底 0.60、高 2.69（= 3.29 − 0.60，**与厢顶对齐**）
车头朝 +Y：厢体 y ∈ [0, 5.4]，驾驶室 y ∈ [5.4, 7.5]，整车长 7.5 m
轴距：后轴 y = 2.7、前轴 y = 6.492 → 3.79 m（真实 75E18 为 3.105 m，取工程近似）
车轮：轮心 |x| = 0.94、半径 0.48、胎宽 0.30
坡道：顶端 (0, 0, 0.95)、长 1.6、下倾 18°
世界包围（Blender 实测）：x ∈ [−1.35, 1.35] · y ∈ [−1.53, 7.62] · z ∈ [0, 3.52]
```
尺寸来源：用户《补充说明》第 11 行（Iveco Eurocargo 75E18）· 与 `TruckScene.cs` 同一套常量。

## 三、⚠ 本会话发现的两处**待修**（诚实列出）

1. **`cab_windshield` 与 `cab_body` 前脸可能仍有穿插**：驾驶室前脸在 y = 7.5，挡风玻璃中心 y = 7.47、厚 0.04 → 前表面 7.49，理论在内侧；但等轴测图角度看不出，**需出一张正面图确认**（下一轮补 `--view front`）。
2. **没做 UV / 贴图**：目前只有纯色 PBR 材质（6 层）。要做"上色"，还需 UV 展开 + 贴图（用户《补充说明》第 3 条"**重点是建模上色，目前的建模上色都不行**"）。这属于下一步，不在本轮样板范围。

## 四、等你确认后的两条路

| 选项 | 内容 |
|---|---|
| **A. 推广到全部套件** | 把倒角/材质分层/细节件的做法搬回 `tools/gen-kits.mjs`（11 个套件共用同一构建路径），并**拆低/精两套**（远处低模、近处精模）以控面数 |
| **B. 只精做关键资产** | 货车 + 大厅场景精做；地图房间套件保持低模（它们数量多、玩家停留短） |

**面数参考**：现有套件 692–1008 面；本样板 3104 面。若 A 方案全量替换，需先定低/精两档的阈值。
