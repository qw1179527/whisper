## 0. 十条必须知道的事实（每条都是花了代价换来的）

1. **真源目录**：`D:\DSH专用\whisper`。Android 出包**必须走纯 ASCII junction** `D:\dsh-whisper-unity` → `whisper\unity`。
   仓库根也有个 ASCII junction：**`D:\dshr` → `D:\DSH专用\whisper`**（我建的）。
   **所有 bash/node 命令都从 `D:\dshr` 走** —— 否则中文路径会被 `sh`/PowerShell 编码毁掉。
2. **出包命令**：`bash tools/build-android.sh <N>`。产物 `unity/build/Android/whisper-android-0.1.<N>-code<N>.apk`。
   当前已到 **0.1.69**。
3. **装机取证**：`bash tools/device-verify.sh <N> [x y]`（会自动唤醒+解锁，可带坐标注入点击）。
   设备 RMX5062 / Android 16，包名 `com.whisper.projectwhisper`。
4. **门禁**：`bash tools/unity-syntax-check.sh`（Roslyn 语法预检）、`bash tools/unity-tests.sh EditMode`
   （真 Unity 编译 + 单测，当前 **45/45 全绿**）。
   ⚠ 语法预检**抓不到跨文件/成员名错误**（CS0103/CS0117/CS1503/CS0234 等）—— 那些只有真 Unity 编译才报。
   所以**每轮改动都要过 `unity-tests.sh EditMode` 或至少出一次包**。
5. **`data/config.json` 改完必须同步镜像**：`node tools/force-sync-config.mjs`（或 `tools/data-mirror.mjs --sync`）。
   镜像有 3 份（`unity/Assets/Data/`、`unity/Assets/Resources/Data/`、`native/micprobe/res/raw/`）。
   我为此白烧过一个包（真机商店显示"配置里没有 shop.items"）。
6. **`Debug.Log` 在 release IL2CPP 里时有时无** → **所有真机取证走 HUD**（屏幕上的文字）。
   这在本项目是硬经验：诊断信息必须能被截屏读到，不能只写日志。
7. **本工程只有 `Boot.unity` 一个场景**（arch-guard 限制）→ 所有 UI 必须**代码构建**，
   没有世界空间画布可用（Canvas 是 ScreenSpaceOverlay）。
8. **Canvas 是 `ScaleWithScreenSize` + `referenceResolution = 1920x1080`**，而真机 2800x1280
   → **`scaleFactor ≈ 1.458`**。`WorldToScreenPoint` 给的是**屏幕像素**，写进 `anchoredPosition`
   必须**除以 `canvas.scaleFactor`**（那是画布单位）。这是"坐标看着对但文字飞出屏幕"的根因。
9. **着色器不进语法门禁**，只有出包日志能验证。已踩过并写进文件头：
   gles3/vulkan 转译器**不支持嵌套三元**（`a?b:c?d:e` 报 syntax error）、
   `[unroll]` 不能包 `continue`、多 pass 着色器**每个 pass 都要各自声明用到的 uniform**。
10. **确定性纪律（门禁强制）**：禁用 `UnityEngine.Random`、`DateTime.Now/UtcNow`。
    一律用整数哈希 / xorshift32。连注释里出现 `Random.Range` 字样都会被 gate 判红。
