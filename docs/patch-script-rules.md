# 补丁脚本编写纪律（whisper 仓 · 2026-10-05 立）

> **为什么立这份文件**：本会话我**连续 5 次**在同一个坑里栽跟头 —— 用内联 `node -e` 或
> 在 `.mjs` 里用引号拼 C# 代码，脚本本身的 JS 语法被自己写坏，白跑一轮。
> 这不是"手滑"，是**方法错了**。下面是经过 5 次事故总结出的硬规则。

## 一、绝对禁止：内联 `node -e` 做文本替换
PowerShell 会先吃掉一层引号，中文引号（`"` `"`）与嵌套引号必炸。本会话实测 5 次全失败。
**唯一例外**：脚本里**不含任何引号**（纯数字/标识符操作）。

## 二、补丁内容里的这些字符**必须转义或避开**
| 字符 | 后果 | 做法 |
|---|---|---|
| **反引号 `` ` ``** | 在 JS 模板串里是**定界符**，直接终止字符串 | **绝不在模板串里写 markdown 代码围栏**；用缩进代替 |
| 中文引号 `"` `"` | 虽不是 JS 定界符，但常与相邻 `'` 混淆、易被 shell 预处理 | 在 C# 注释里改用「」或直接去掉 |
| `\n` 拼接 | 数组 + join 时可读，模板串里易与真实换行混淆 | **统一用 `['a','b'].join('\n')`** |
| `${...}` | 模板串插值，会吃掉 C# 里的 `$"..."` | 补丁内容一律用**普通引号串**，不用模板串 |

## 三、首选做法：**用 `edit` 工具直接改目标文件**
当改动是"把这一段换成那一段"时，`edit` 工具没有中间层 —— **没有脚本，就没有脚本语法错误**。
本会话后半段凡改用 `edit` 的都一次通过。

## 四、需要脚本时（幂等/可重跑/批量）的写法
```js
// ✅ 正确：数组 + join，普通引号，不含反引号
const out = [
  '        /// <summary>',
  '        /// 普通注释，不用 markdown 围栏',
  '        /// </summary>',
  '        static float Clamp01(float v) => v < 0f ? 0f : (v > 1f ? 1f : v);',
].join('\n');
```
```js
// ❌ 错误：模板串 + 反引号 + 缩进换行，必炸
const out = `
        /// \`\`\`
        /// 公式
        /// \`\`\`
`;
```

## 五、写完立刻自检（**在跑补丁之前**）
```bash
node --check tools/<脚本>.mjs     # 先保证脚本自己是合法 JS
```
本会话有 5 次是"直接跑、脚本自己语法错"，白跑一轮。**`--check` 只要 200ms。**

## 六、锚点纪律（同样吃过亏）
- 锚点必须**从文件里读出来**（grep 行号 + 看真实缩进），**不能凭记忆**；
- 脚本里保留"命中 ≠ 1 就停止且不写盘"的保护 —— 它已救过我好几次（如误判"重复建车"那次）；
- **`Select-String -Context` 会把相邻匹配拼在一起**，判断"是否重复"必须先看行号。

## 七、跨程序集引用纪律
用某类型的成员前，**先确认它所在程序集是否引用 UnityEngine**：
- `Whisper.Gameplay`（理智/关卡/道具/配置）**不引用 UnityEngine** → 不能用 `Vector3`/`Mathf`/`Debug`
  （第 17 轮实测 `CS0246`；第 31 轮 `Mathf.Clamp01` 又一次）
- `Whisper.Runtime`（MonoBehaviour 层）有 Unity → 可以用
